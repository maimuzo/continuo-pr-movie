# 自分の分だけ上書きの回　詳しいコンテ

**言いたいこと。**「チームで共有する WORKFLOW.md はそのまま、隣に置いた WORKFLOW.local.md に書いた行だけが自分の機械で効く」を30秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [short_movie/concept.md](../concept.md) の「自分の分だけ上書きの回」の表と1節の共通の決まりが正である。部屋・机3つ・電池は、チームで入札の回（[team-bid.md](team-bid.md)）と寝て待つ回（[wait-quota.md](wait-quota.md)）と同じ見た目にし、電池の「自分の分」の点線は、どの日も自分の分が残る回（[weekly-margin-by-days.md](weekly-margin-by-days.md)）と同じにする。
キャラクターの見た目は [short_movie/characters.md](../characters.md) にある。出るのは Claude Code（3体）・開発者・アカネ・ゲンさんで、コンティと Codex は出ない。

## 1. 共通の決まり

**言いたいこと。**チームで入札の回の部屋を1カットで使い、壁の WORKFLOW.md の紙と、机ごとの電池の点線で話を運ぶ。前半（共有の紙を書き換えてしまう）と後半（WORKFLOW.local.md を使う）は、巻き戻しと「仕切り直し」の札ではっきり区切る。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、900フレーム（30秒） | 共有の紙を書き換えた場面と WORKFLOW.local.md の場面を、区切って両方見せるため（人間の指示 https://github.com/maimuzo/continuo-pr-movie/issues/6#issuecomment-6696961635 ） |
| カット | チームで入札の回の部屋の1カット。カメラは動かさない（巻き戻しのあいだだけ、画面を左右に小さく揺らす） | 同じチームの話として読めるようにする |
| 部屋の部品 | `short_movie/videos/_shared/TeamRoom.tsx` の部屋・机3つ・Claude Code 3体をそのまま使う。机の左はアカネ、真ん中は開発者、右はゲンさん（寝て待つ回と同じ並び） | チームで入札の回・寝て待つ回と見た目をそろえる |
| 壁の紙 | 共有のカンバンの代わりに、壁の真ん中（左 300px・上 40px・幅 480px・高さ 270px）に白い紙。見出し「WORKFLOW.md（チームで共有）」、中に「マージン 10%」。字は見出し 28px・中 40px（見出しは 40px では紙の幅に収まらない）。書き換えるときは「10%」に赤い線を引き、その下に赤い手書きの「0%」（54px）を書き込む | チームで共有する設定が1枚であることを見せる。書き換えたことが、字幕なしでも分かるようにする |

| 付箋 | 開発者の机の天板の右端に、黄色い付箋（108×124px）を人より奥に立てる。見出し「WORKFLOW」「.local.md」の2行、中に「マージン」「0%」（字 16px・23px・30px）。開発者の机の Claude Code だけ 25px 左へ寄せ、付箋で目を隠さない | 自分の机にだけ置くファイルであることを見せる。前板に置くと、机の前に立つ人に隠れる |
| 名前の札 | 3.05〜4.35秒、3体の Claude Code の頭の上にテラコッタの札（寝て待つ回と同じ位置） | 1節の決まり |

## 2. 場面ごとの作り

**言いたいこと。**本編の5場面を concept.md の5行と1対1に対応させる。秒は動画の頭からの秒である。前半（3〜11秒）は「場面の時刻」で動かし、巻き戻しはその時刻を 11秒から 3秒へ逆に進めて、全部の部品を逆に動かす。

| 秒 | 場面 | 中身 |
| --- | --- | --- |
| 0〜3 | タイトル | 部屋の上に「自分の分だけ、上書き」。2.7秒から縮んで消える |
| 3〜7 | 自分の都合で、共有の紙を書き換える | 3.05秒に名前の札。3.2秒に開発者の机の日めくりが「あと1日」で光り、3.6秒に開発者が思いつく（`dev_notice`・きらり）。4.0〜4.4秒に開発者が `dev_reach_pen` の姿で壁の紙の右下（足もと 800px・515px、高さ 340px）へ跳んで行き、紙の「10%」が光る。4.6〜5.1秒に「10%」へ赤い線を引き、5.3〜5.9秒にその下へ赤い「0%」を書き込む。6.4〜6.8秒に机の前へ戻る（`dev_notice`）。開発者の机の Claude Code は点線のところで待っている（`cc_wait`）。字幕「自分の都合で、共有の WORKFLOW.md を書き換えると」 |
| 7〜11 | みんなの設定が変わってしまう | 7.2〜7.5秒に3つの電池の点線がそろって右の端まで寄って消える。7.6秒から3体の Claude Code が猛烈に作り（スピード線、アカネとゲンさんの机は汗）、電池が 10.6秒までにどんどん減る（アカネ 66→12%・ゲンさん 78→16%）。9.4秒にアカネとゲンさんが気づいて驚く（`akane_surprised`・`gen_surprised`、頭の横に「！」、吹き出し「えっ！？」）。壁の紙は書き換えたまま。字幕「共有の WORKFLOW.md は、みんなの設定」 |
| 11〜13.5 | 巻き戻して仕切り直し | 11.0秒から右上に「◀◀ 巻き戻し」の印、画面に走査線と揺れ。11.15〜12.6秒に場面の時刻を 11秒から 3秒へ戻す（2人が元の顔へ、電池の残りと点線が元へ、開発者が壁から机へ戻り、紙の「0%」と線が消えて「10%」へ）。12.8秒に画面を少し暗くし、真ん中に大きく「仕切り直し」の札（136px）が弾んで出て、13.35〜13.5秒に消える。字幕「元に戻して、仕切り直し」 |
| 13.5〜21 | 自分の机にだけ付箋 | 14.2秒に開発者が自分の机の天板の右端に付箋を貼る（`dev_pin`。付箋がぽんと出る）。15.0〜15.6秒に付箋に「マージン 0%」の字が書かれる。16.0〜16.35秒に開発者の電池の点線だけが右の端まで寄って消え、その電池が 1.3倍に膨らんで光り（16.0〜16.8秒）、16.1秒に開発者の Claude Code が作り始める（スピード線）。アカネとゲンさんの電池の点線と壁の紙は動かない（17.0秒に壁の紙が一度だけ小さく光り、「そのまま」を示す）。字幕「WORKFLOW.local.md に書いた行は、自分だけに適用される」 |
| 21〜27 | チームの設定はそのまま | 3体の Claude Code がそれぞれ楽しそうに作る（困った顔・目が回る顔にしない。上書きした机が無理をしているように見えるため）。21.6秒にアカネとゲンさんがほっとして笑う（`akane_relief`・`gen_relief`）。22.0秒に開発者が喜ぶ（`dev_cheer`）。壁の紙は「マージン 10%」のまま（24.0秒にもう一度小さく光る）。字幕「チームの設定は、そのまま」 |

**Remotion で描くもの。**この回のフォルダの `Props.tsx` に置く。壁の紙（`WorkflowSheet`。赤い線と手書きの「0%」を含む）・付箋（`LocalNote`）・机の日めくり（`MiniCalendar`）・点線の付いた電池（`MarginBattery`。どの日も自分の分が残る回と同じ記号）・巻き戻しの印（`Rewind`。寝て待つ回の「早回し」の印の向きを逆にしたもの）・走査線（`Scanlines`）・「仕切り直し」の札（`ResetSign`）・「えっ！？」の吹き出し（`Shout`）。部屋・机・Claude Code は `../_shared/TeamRoom`、色は `../_shared/theme`。
