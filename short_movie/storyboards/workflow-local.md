# 自分の分だけ上書きの回　詳しいコンテ

**言いたいこと。**「チームで共有する WORKFLOW.md はそのまま、隣に置いた WORKFLOW.local.md に書いた行だけが自分の機械で効く」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [short_movie/concept.md](../concept.md) の「自分の分だけ上書きの回」の表と1節の共通の決まりが正である。部屋・机3つ・電池は、チームで入札の回（[team-bid.md](team-bid.md)）と寝て待つ回（[wait-quota.md](wait-quota.md)）と同じ見た目にし、電池の「自分の分」の点線は、どの日も自分の分が残る回（[weekly-margin-by-days.md](weekly-margin-by-days.md)）と同じにする。
キャラクターの見た目は [short_movie/characters.md](../characters.md) にある。出るのは Claude Code（3体）・開発者・アカネ・ゲンさんで、コンティと Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**チームで入札の回の部屋を1カットで使い、壁の WORKFLOW.md の紙と、机ごとの電池の点線で話を運ぶ。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 1節の決まり |
| カット | チームで入札の回の部屋の1カット。カメラは動かさない | 同じチームの話として読めるようにする |
| 部屋の部品 | `short_movie/videos/_shared/TeamRoom.tsx` の部屋・机3つ・Claude Code 3体をそのまま使う。机の左はアカネ、真ん中は開発者、右はゲンさん（寝て待つ回と同じ並び） | チームで入札の回・寝て待つ回と見た目をそろえる |
| 壁の紙 | 共有のカンバンの代わりに、壁の真ん中（左 300px・上 40px・幅 480px・高さ 270px）に白い紙。見出し「WORKFLOW.md（チームで共有）」、中に「マージン 10%」。字 40px | チームで共有する設定が1枚であることを見せる |
| 電池 | 各 Claude Code の頭の上に「1週間」の電池を1本（寝て待つ回と同じ大きさ）。中に「自分の分」の点線を 10% の高さで引く | 壁の紙の 10% が、全部の机に効いていることを見せる |
| 机の日めくり | 各机の前板の左に小さな日めくり（幅 90px）。開発者は「あと1日」、アカネは「あと4日」、ゲンさんは「あと6日」 | リセットの時刻が机ごとに違うことを見せる |
| 人 | 3人とも、自分の机の前に上半身で立つ（下端は画面の下で切れる。高さ 380px）。ふだんは前を向く | 机の前板の顔のアイコンと同じ人だと読み取れるようにする |
| 付箋 | 開発者の机の前板の右に、黄色い付箋（110×110px）。見出し「WORKFLOW.local.md」、中に「マージン 0%」（字 22px と 30px） | 自分の机にだけ置くファイルであることを見せる |
| 名前の札 | 2.05〜3.35秒、3体の Claude Code の頭の上にテラコッタの札（寝て待つ回と同じ位置） | 1節の決まり |
| 字幕・締め | 場面の頭から4フレーム後に1行。締め「チームの設定と、自分の都合の両立」は2行（「チームの設定と、」「自分の都合の両立」）に分けて 110px | 15字を1行にすると画面に収まらない |
| 描かないもの | 入札・％の余裕値・本文（プロンプト）の上書き | 上書きした機械は入札の条件も変わるので、入札を描くと誤解を生む（continuo の FAQ）。本文の上書きは15秒に入らない |

## 2. 場面ごとの作り

**言いたいこと。**本編の3場面を concept.md の3行と1対1に対応させる。秒は動画の頭からの秒である。

| 秒 | 場面 | 中身 |
| --- | --- | --- |
| 0〜2 | タイトル | 部屋の上に「自分の分だけ、上書き」。1.7秒から縮んで消える |
| 2〜5 | 共有の紙は書き換えられない | 開発者の机の日めくりが「あと1日」で光る。2.6秒に開発者がペンを持って壁の紙の「10%」へ手を伸ばす（`dev_reach_pen`。紙の「10%」が光る）。3.3秒にアカネとゲンさんが振り向いて驚く（`akane_surprised`・`gen_surprised`。頭の上に「！」）。4.2秒に開発者が手を引っ込める。字幕「共有の WORKFLOW.md は、みんなの設定」 |
| 5〜10 | 自分の机にだけ付箋 | 5.4秒に開発者が自分の机に付箋を貼る（`dev_pin`。付箋がぽんと出る）。6.2秒に付箋に「マージン 0%」の字が書かれる。6.8秒に開発者の電池の点線だけが上の端まで上がって消え、開発者の Claude Code が作り始める（スピード線）。アカネとゲンさんの電池の点線と壁の紙は動かない（7.5秒に壁の紙が一度だけ小さく光り、「そのまま」を示す）。字幕「WORKFLOW.local.md に書いた行だけ、自分の機械で上書き」 |
| 10〜13 | チームの設定はそのまま | 3体の Claude Code がそれぞれ作る。アカネとゲンさんがほっとして笑う（`akane_relief`・`gen_relief`）。開発者が喜ぶ（`dev_cheer`）。壁の紙は「マージン 10%」のまま。字幕「チームの設定は、そのまま」 |
| 13〜15 | 締め | 「チームの設定と、」「自分の都合の両立」・「continuo」・URL・ヒレを振るコンティ |

### 効果音

| 秒 | 音 | 動き |
| --- | --- | --- |
| 2.05・2.2 | pop・sparkle | 名前の札・日めくりが光る |
| 2.6・3.3 | swish・blocked_huh | 手を伸ばす・振り向いて驚く |
| 4.2 | swish | 手を引っ込める |
| 5.4・6.2 | splat・typing | 付箋を貼る・字を書く |
| 6.8・6.9 | wait-quota_charge・typing | 点線が消える・作り始める |
| 10.3・10.6 | stranger-comment_relief・sparkle | ほっとする・喜ぶ |
| 13.0 | pop | 締めの字 |

`blocked_huh`・`stranger-comment_relief`・`wait-quota_charge` は既存の回の音をそのまま使う。新しく合成する音は無い。
