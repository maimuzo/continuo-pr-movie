# セットアップの回　詳しいコンテ

**言いたいこと。**「依存物を入れ、continuo を入れ、設定して確かめ、起動する」までの順番を、1つの端末の窓に打ち込まれるコマンドで30秒に見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「セットアップの回」の表と1節の共通の決まりが正である。この回には絵コンテが無いので、構図はこの文書で決める。
コマンドの字は continuo の README の「Install」と「Use」の段のとおりにし、1文字も変えない。

---

## 1. 共通の決まり

**言いたいこと。**主役は端末の窓で、React と SVG で描く。字幕は場面の見出しにし、コマンドは窓の中に1文字ずつ打たれる等幅の字で見せる。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、900フレーム（この回だけ30秒） | 入れるものとコマンドが多く、15秒では読み切れなかった。storyboard.md の「この回だけ尺を30秒にする」の段 |
| 打つ間 | 1行を打ち終えてから次の行を打ち始めるまで1秒以上あける。窓の中身は次の行の1文字目が出るコマで入れ替え、端末が `$` だけになる間を作らない | storyboard.md の同じ段 |
| 端末の窓 | 濃い紺の窓に、上の帯（丸い3つの点と題名 `continuo-setup`）。通常は左右 30px あけて置き、長い行の場面と左右に割る場面は画面の幅いっぱいまで広げる | 窓の幅で折り返さずに1行で見せる、と人間が決めたため |
| 書体 | コマンドは JetBrains Mono（`@remotion/google-fonts` から、この回のファイルの中で読む）。札と字幕は共通の丸ゴシック | 等幅でないとコマンドに見えない。`src/theme.ts` は10本で共有するので書き換えない |
| 字の大きさ | 場面ごとにできるだけ大きくする。依存物 26px、continuo の install.sh 36px、設定 44px、macOS だけの行 30px、doctor 38px、起動 34px | スマホの幅で読めるようにする |
| 長い行 | install.sh の URL は、字を変えずに見せる段だけを2つに分け、2段目は2字下げる。依存物の curl は最後の「/」のあと、continuo の行は `githubusercontent.com/` のあとで分ける | 1行のままでは 16〜20px にしかならず、読めなかった |
| ✓ | 1行を打ち終えると、行の右に明るい黄色（`#FFC94D`）の ✓ を SVG で描く | 緑は避けると決めた。書体に ✓ が無くても欠けないよう、字ではなく線で描く |
| 左右に割る | 窓の真ん中に縦の線を引き、左の上に「macOS」、右の上に「Ubuntu」の札を大きく（52px）出す | 2つの OS で操作が違うところだけを分けて見せる |
| 開発者 | 左下で椅子に座ってキーボードを打つ（`developer/typing` を裏返して右向き） | 端末の前に座っている人として置く。顔は伸び縮みさせない |
| コンティ | 端末の窓の右上の角に小さく乗って見守る（`continuo/wave`）。起動の場面で潮を吹く絵（`continuo/leap`）に替わる | コンテのとおり |
| 字幕 | 画面の下に1行。文言は storyboard.md の字幕の列のとおり | 無音で見られるため |
| 締め | 27.0秒の1コマ目から「あとは Ready に置くだけ」を、「あとは」「Ready に置くだけ」の2行で出す | 1行では 1080px に収まらない。字は変えず、改行だけを入れる |

## 2. 場面ごとの作り（0〜18秒）

**言いたいこと。**場面は storyboard.md の行と1対1にする。秒は動画の頭からの秒である。

| 秒 | 窓 | 打たれる行と出来事 |
| --- | --- | --- |
| 0〜2 | 通常の幅、ぼかす | タイトル「セットアップ」 |
| 2.0〜2.25 | 幅いっぱいに広がり、縦の線で左右に割れる。「macOS」「Ubuntu」の札が弾んで出る | 2.0秒の1コマ目から1行目を打ち始める |
| 2.0〜8.0 | 左右に割れたまま | 左 `brew install git gh ghq`、右 `sudo apt install git gh`（2.0〜2.55）→ herdr の install.sh（3.8〜4.35）→ Claude Code の install.sh（5.35〜5.9）→ `gh auth login -s project`（6.9〜7.25）。左右は同じ時刻に打ち、1行ごとに ✓ |
| 8.0〜8.25 | 縦の線が消えて1つに戻る | 8.25秒から continuo の install.sh を2段で打つ（〜9.0） |
| 9.05〜9.75 | 幅いっぱい | 画面の上から点線のネットワークの線が伸び、コンティの顔の丸いアイコンが降りて窓の真ん中に収まる（9.6）。線は引っ込み、9.75秒に ✓。11秒まで残す |
| 11.0〜11.45 | 通常の幅に戻る | `continuo init` を打って ✓ |
| 11.6〜14.0 | 同上 | 紙「WORKFLOW.md」が飛び出して真ん中に大きく出る。上の段に歯車と「設定」、下の段に吹き出しと「プロンプト」。12.4秒から下の段が光り、12.8〜13.4秒に吹き出しが紙の右へ出てコンティへ届く |
| 14.0〜14.25 | 同上 | 紙が縮んで窓の右下に小さく残る |
| 14.4〜14.85 | 同上 | `continuo setup` を打って ✓ |
| 15.0〜16.35 | 同上 | 左に自分の列の名前6つ、右に6つの役を並べ、線でつなぐ絵を出す |
| 16.5〜16.9 | 同上 | `continuo trust` を打って ✓。18秒まで残す |

**紙の札は 60px 以上の字にする。**人間が「WORKFLOW.md は設定ファイル＋continuo で使うプロンプト」と見せたいと決めたので、紙の2段の札が動画の大きさで読めることを優先する。

**列の名前と役の対応は README の Status の表から取る。**左は `Todo`・`In Progress`・`Needs review`・`Blocked`・`Done`・`Direct Chat`、右は `Ready`・`In Progress`・`In Review`・`Blocked`・`Done`・`Direct Chat` とする。README に「`Ready` or `Todo`, `In Review` or `Needs review`」とあり、名前が違ってもつなげられることを見せるためである。

## 3. 場面ごとの作り（18〜30秒）

**言いたいこと。**後半は、macOS だけの1行と確かめ、起動して一覧が出るまでと、締めである。

| 秒 | 窓 | 打たれる行と出来事 |
| --- | --- | --- |
| 18.0〜18.25 | 幅いっぱいに広がり、左右に割れる。左を 62%、右を 38% にする | 18.0秒から左だけに `continuo allow-keychain-access` を打って ✓（〜18.55） |
| 18.7 | 同上 | 右に「不要」の札が弾んで出る |
| 19.8〜20.1 | 1つに戻り、通常の幅 | 20.1秒から `continuo doctor` を打つ |
| 20.6〜22.2 | 同上 | 9つの確かめの名前が、頭に ✓ を付けて 0.2秒ずつ上から順に並ぶ。23秒まで残す |
| 23.0〜23.45 | 通常の幅 | `continuo --port 8080` を打って ✓ |
| 23.6〜 | 窓が左へ縮む | 23.9秒にコンティが潮を吹く絵に替わって跳ねる。24.1秒に窓の右にブラウザの小窓が開き、上に `localhost:8080`、中に動いている issue の一覧の行が 0.25秒ずつ出る |
| 27〜30 | 締め | 「あとは」「Ready に置くだけ」、下に小さく「continuo」と `github.com/maimuzo/continuo`、その下にコンティ |

**左右の割り方を場面で変える。**macOS だけの行の場面は、右に「不要」の札しか無いので、左を広くして字を大きくする。

**doctor の確かめの名前は README の「eighteen checks」の並びから9つを取る。**18個すべてを並べると字が小さくなりすぎるためである。

## 4. 要る絵と部品

**言いたいこと。**新しく描いた絵は無い。キャラクターは既存の3枚を使い、端末・紙・札・ブラウザは Remotion で描く。

| 絵・部品 | 中身 | 作り方 |
| --- | --- | --- |
| `developer/typing` | 椅子に座って打つ開発者 | 既存の絵 |
| `continuo/wave`・`leap` | 見守るコンティ・潮を吹いて跳ねるコンティ。顔のアイコンは `wave` を丸く切り抜く | 既存の絵 |
| `src/videos/setup/Terminal.tsx` | 端末の窓・打たれる行・✓・左右の札 | Remotion |
| `src/videos/setup/Props.tsx` | WORKFLOW.md の紙・吹き出し・列と役の対応の絵・ブラウザの小窓・ネットワークの線 | Remotion |
| `src/videos/setup/EndCard.tsx` | 締めを2行にした写し | 共通の EndCard を写して直す |
