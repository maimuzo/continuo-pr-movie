# どの日も自分の分が残る回　詳しいコンテ

**言いたいこと。**「1週間のレートリミットのうち自分で使う分を、リセットまでの残り日数ごとに決められるので、いつでも自分の分が残り、リセット直前は余りを使い切れる」を30秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [short_movie/concept.md](../concept.md) の「どの日も自分の分が残る回」の表と1節の共通の決まりが正である。部屋の絵・机・電池・日めくりは、寝て待つ回（[wait-quota.md](wait-quota.md)）と同じ見た目にする。
キャラクターの見た目は [short_movie/characters.md](../characters.md) にある。出るのはコンティ・Claude Code（1体）・開発者で、Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**部屋の1カットで、真ん中の大きな「1週間」の電池と「自分の分」の点線、右上の日めくりで話を運ぶ。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、900フレーム（30秒） | 15秒では展開が早すぎて伝わらなかったので、30秒に延ばした（issue #6 の人間のコメント） |
| カット | チームで入札の回の部屋の絵（`ep/team-bid/room.png`）の1カット。カメラは動かさない | 寝て待つ回の続きとして読めるようにする |
| 机とロボット | 右寄りに机を1つ（`ep/team-bid/desk.png`。左端 560px・上辺 735px・幅 400px）。Claude Code は机の後ろ（中心 760px） | 開発者の机1つで話を運ぶ |
| 電池 | Claude Code の頭の上に「1週間」の電池を1本、寝て待つ回の2倍（幅 300px）。中心 760px・上辺 330px。札「1週間」は電池の上 | この回の主役なので大きくする |
| 自分の分 | 電池は横向きで、たまるときは左から右へ伸びる（寝て待つ回と同じ）。満タン側の右端からマージンの幅のところに縦の点線（白地に濃い茶の破線、太さ 6px）。点線より右（自分の分）は、残りの黄色の上に白い薄い斜線を重ねる。Claude Code が使うときは、残りの左の端が右へ寄り、点線で止まる。点線より右の黄色が、開発者に残る自分の分。電池の上に「自分の分」の札（ハイライトの色、字 34px）を出し、斜線の部分を指す | 開発者が自分で使う分の境目を、字幕なしでも読めるようにする。点線が右端からの幅なので、残りが点線で止まって見えるよう、使う向きは左から右にした。コンテの「点線が電池の上の端まで上がって消える」は、横向きの電池では「点線が右の端まで寄って消える」として描く |
| 日めくり | 右上（左 860px・上 70px・幅 190px）。寝て待つ回の日めくりの数字の代わりに「リセットまで」「あと N日」を2段で出す。めくるあいだ（12〜20秒）は 1.2 倍にし、日めくりの上（左 878px・上 2px）に「早回し」の印 | 残り日数で点線の位置が変わることを見せる |
| 開発者 | 左（中心 250px・足もと 960px・高さ 430px）。ノートPC で自分の Claude Code を使う | 開発者が自分で使う分が残っているかを見せる |
| コンティ | 電池の左（中心 520px・上 420px）に浮かび、カードを Claude Code へ渡す。点線まで来たらカードを抱えたまま待つ | マージンに食い込む前に、continuo が新しい作業を渡さないことを見せる（continuo の FAQ） |
| 看板 | 10.6〜21秒、電池の左上（左 330px・上 60px・幅 360px）に「自分の分」の表。あと7日 85%・あと6日 70%・あと5日 55%・あと4日 45%・あと3日 30%・あと2日 15%（1週間を残り日数で7等分し、5%刻みに丸めた値）。字 30px。あと1日の行は出さない。日めくりがその日を指しているあいだ、その日の行を黄色に光らせる | 残り日数ごとに決められることを、表の形で一目で見せる。％は例。0% は次の場面で初めて見せる。残り7日で7割を使えるような値にしない（人間の指示） |

## 2. 場面ごとの作り

**言いたいこと。**本編の3場面を concept.md の3行と1対1に対応させる。秒は動画の頭からの秒である。

| 秒 | 場面 | 中身 |
| --- | --- | --- |
| 0〜3 | タイトル | 部屋の上に「いつでも、」「自分の分は残ってる」の2行。2.7秒から縮んで消える |
| 3〜10 | 週の途中で使い切る | 点線の無い電池（残り 70%）。日めくり「あと4日」。3.1秒に名前の札。3.4・4.6・5.8・7.0秒にコンティがカードを Claude Code へ渡し（カードが飛ぶ）、Claude Code が激しく作る（スピード線と汗）。電池が 3.4〜7.5秒でゆっくり空になり、7.5秒から赤く点滅して中に「！」。Claude Code は座り込み（`cc_wait`）、コンティは慌てる（`fluster`）。8.2秒に開発者（ノートPC）が自分の作業を始めようとすると、ノートPC に赤い「×」。9.0秒に開発者が青ざめる（`dev_pale`）。字幕「週の途中で使い切ると、残りの日に AI が使えない」 |
| 10〜21 | 残り日数ごとに自分の分 | 10.0秒に電池が満タンへ戻る（この場面は別の週）。10.35秒に点線と「自分の分」の札が 85% の位置に出る（ぽん）。10.6秒に看板が出て「あと7日」の行が光る。10.8秒にカードを渡し、11.1〜11.8秒に Claude Code が作って残りが点線まで減る。12.2・13.8・15.4・17.0・18.6秒（1日あたり 1.6秒）に日めくりが1枚ずつめくれ（あと6日 → 5 → 4 → 3 → 2）、めくるたびに看板のその日の行が光り、めくり終わりの 0.35秒後から点線がその日の％の位置へ右へ寄る。めくりの 0.5秒後にカードを渡し、0.85〜1.3秒後に Claude Code が作って残りが点線まで減る。点線に届いたら Claude Code は手を止め、コンティは次のカードを抱えたまま待つ。開発者はノートPC で作業し（`dev_laptop`）、16.4〜18.4秒に喜ぶ（`dev_cheer`）。字幕「残り日数ごとに、自分の分を残せる」 |
| 21〜27 | 最後の日は使い切る | 21.0秒に日めくり「あと1日」。看板は消える。21.8〜22.4秒に点線が電池の右の端までゆっくり寄り、札が「0%」になって、22.4〜22.8秒に消える。23.0秒にコンティがカードを渡し、Claude Code が作って残りが 23.4〜25.2秒で空になる（赤くならない）。25.7秒にベルが鳴り、25.75秒から電池が満タンへ戻る（困った場面の空の電池と取り違えないよう、満タンへ戻るところを必ず見せる）。日めくりが「あと7日」へ戻る。26.3秒に Claude Code がこぶしを上げる（`fist`）。字幕「リセット直前は、余りを使い切る」 |
| 27〜30 | 締め | 「毎日使えて、」「余らせない」・「continuo」・URL・ヒレを振るコンティ |

## 3. 要る絵の一覧

**言いたいこと。**新しく描く絵は無い。キャラクターと部屋は既存の絵、電池・点線・看板・日めくりは Remotion の部品で作る。

| 絵 | 中身 | 作り方 |
| --- | --- | --- |
| `ep/team-bid/room`・`desk` | 部屋・机 | チームで入札の回の絵をそのまま使う |
| `characters/claude_code/work`・`fist`・`receive` | 作る・こぶし・受け取る | 既存 |
| `ep/team-bid/cc_wait` | 電池が空になって座り込む Claude Code | チームで入札の回の絵をそのまま使う |
| `characters/continuo/wave`・`fluster` | ヒレを振る（運ぶ・待つ）・慌てる | 既存 |
| `ep/direct-chat/dev_laptop`・`ep/flat-rate/dev_pale`・`ep/resume/dev_cheer` | ノートPC で作業する・青ざめる・喜ぶ | 既存 |

**Remotion で描くもの。**寝て待つ回の `LabeledBattery`・`DayCalendar`・`FastForward` を、この回のフォルダへ写して直す（ほかの回のフォルダは import できないため。寝て待つ回のファイルは変えない）。直すのは、電池の大きさ・点線と「自分の分」の札（`MarginBattery`）・日めくりの「あと N日」の2段（`DaysLeftCalendar`）。看板（`MarginTable`）・カード（`../_shared/IssueCard`）・締め（寝て待つ回の `WaitEndCard` の形を写す）。色は `../_shared/theme`。
