# どの日も自分の分が残る回　詳しいコンテ

**言いたいこと。**「1週間のレートリミットのうち自分で使う分を、リセットまでの残り日数ごとに決められるので、いつでも自分の分が残り、リセット直前は余りを使い切れる」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [short_movie/concept.md](../concept.md) の「どの日も自分の分が残る回」の表と1節の共通の決まりが正である。部屋の絵・机・電池・日めくりは、寝て待つ回（[wait-quota.md](wait-quota.md)）と同じ見た目にする。
キャラクターの見た目は [short_movie/characters.md](../characters.md) にある。出るのはコンティ・Claude Code（1体）・開発者で、Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**部屋の1カットで、真ん中の大きな「1週間」の電池と「自分の分」の点線、右上の日めくりで話を運ぶ。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 1節の決まり |
| カット | チームで入札の回の部屋の絵（`ep/team-bid/room.png`）の1カット。カメラは動かさない | 寝て待つ回の続きとして読めるようにする |
| 机とロボット | 右寄りに机を1つ（`ep/team-bid/desk.png`。左端 560px・上辺 735px・幅 400px）。Claude Code は机の後ろ（中心 760px） | 開発者の机1つで話を運ぶ |
| 電池 | Claude Code の頭の上に「1週間」の電池を1本、寝て待つ回の2倍（幅 300px）。中心 760px・上辺 330px。札「1週間」は電池の上 | この回の主役なので大きくする |
| 自分の分 | 電池の中に、マージンの高さで横の点線（白地に濃い茶の破線、太さ 6px）。点線の右に「自分の分」の札（ハイライトの色、字 34px）。点線より上は薄い斜線 | 開発者が自分で使う分の境目を、字幕なしでも読めるようにする |
| 日めくり | 右上（左 860px・上 70px）。寝て待つ回の日めくりの数字の代わりに「リセットまで」「あと N日」を2段で出す。めくるあいだは大きくし、右上に「早回し」の印 | 残り日数で点線の高さが変わることを見せる |
| 開発者 | 左（中心 250px・足もと 960px・高さ 430px）。ノートPC で自分の Claude Code を使う | 開発者が自分で使う分が残っているかを見せる |
| コンティ | 電池の左（中心 520px・上 420px）に浮かび、カードを Claude Code へ渡す。点線まで来たらカードを抱えたまま待つ | マージンに食い込む前に、continuo が新しい作業を渡さないことを見せる（continuo の FAQ） |
| 看板 | 5〜10秒、電池の左上（左 330px・上 60px・幅 360px）に「自分の分」の表。あと7日 30%・あと5日 15%・あと2日 5%・あと1日 0%。字 30px | 残り日数ごとに決められることを、表の形で一目で見せる。％は例 |
| 名前の札 | 2.05〜3.35秒、Claude Code の頭の上にテラコッタの札。電池の上に重ならないよう、札は電池の左に出す | 1節の決まり |
| 字幕・締め | 場面の頭から4フレーム後に1行。締め「毎日使えて、余らせない」は2行に分けて 120px | チームで入札の回・寝て待つ回と同じ形 |
| 言葉 | 字幕と画面の字で「マージン」と書かず「自分の分」と書く。レートリミットは言い換えない | 読む人の言葉にする（`lessons.md`） |

## 2. 場面ごとの作り

**言いたいこと。**本編の3場面を concept.md の3行と1対1に対応させる。秒は動画の頭からの秒である。

| 秒 | 場面 | 中身 |
| --- | --- | --- |
| 0〜2 | タイトル | 部屋の上に「いつでも、自分の分は残ってる」。1.7秒から縮んで消える |
| 2〜5 | 週の途中で使い切る | 点線の無い電池（残り 70%）。日めくり「あと4日」。2.2・2.8・3.4秒にコンティがカードを Claude Code へ渡し（カードが飛ぶ）、Claude Code が激しく作る（スピード線と汗）。電池が 2.2〜4.0秒で空になり、赤く点滅して中に「！」。4.1秒に開発者（ノートPC）が自分の作業を始めようとすると、画面に赤い「×」。4.4秒に開発者が青ざめる（`dev_pale`）。字幕「週の途中で使い切ると、残りの日に AI が使えない」 |
| 5〜10 | 残り日数ごとに自分の分 | 5.0秒に電池が満タンへ戻り（この場面は別の週）、点線と「自分の分」の札が 30% の高さに出る（ぽん）。看板が出る。日めくり「あと7日」。5.6〜9.4秒に日めくりが「あと7日」から「あと2日」まで5枚めくれる。めくるたびに点線が看板の％の高さへ下がり、電池の残りは点線まで減る（Claude Code が作る）。点線に届くたびにコンティはカードを抱えたまま止まる。開発者はノートPC で作業し（`dev_laptop`）、8.5秒に喜ぶ（`dev_cheer`）。字幕「残り日数ごとに、自分の分を残せる」 |
| 10〜13 | 最後の日は使い切る | 10.0秒に日めくり「あと1日」。10.3秒に点線が電池の上の端まで上がって消え、札が「0%」になって消える。10.6秒にコンティがカードを渡し、Claude Code が作って電池が 10.6〜12.0秒で空になる（赤くならない）。12.2秒にベルが鳴り、電池が満タンへ戻る。日めくりが「あと7日」へ戻る。12.5秒に Claude Code がこぶしを上げる（`fist`）。字幕「リセット直前は、余りを使い切る」 |
| 13〜15 | 締め | 「毎日使えて、」「余らせない」・「continuo」・URL・ヒレを振るコンティ |

| 5.0・5.05 | wait-quota_charge・pop | 満タン・点線が出る |

`wait-quota_*` は寝て待つ回の音（`short_movie/materials/sfx/sfx_wait-quota.py`）、`blocked_bonk` は詰まったらひとことの回の音をそのまま使う。新しく合成する音は無い。

## 3. 要る絵の一覧

**言いたいこと。**新しく描く絵は無い。キャラクターと部屋は既存の絵、電池・点線・看板・日めくりは Remotion の部品で作る。

| 絵 | 中身 | 作り方 |
| --- | --- | --- |
| `ep/team-bid/room`・`desk` | 部屋・机 | チームで入札の回の絵をそのまま使う |
| `characters/claude_code/work`・`fist`・`receive` | 作る・こぶし・受け取る | 既存 |
| `characters/continuo/wave`・`fluster` | ヒレを振る（運ぶ・待つ）・慌てる | 既存 |
| `ep/direct-chat/dev_laptop`・`ep/flat-rate/dev_pale`・`ep/resume/dev_cheer` | ノートPC で作業する・青ざめる・喜ぶ | 既存 |

**Remotion で描くもの。**寝て待つ回の `LabeledBattery`・`DayCalendar`・`FastForward` を、この回のフォルダへ写して直す（ほかの回のフォルダは import できないため。寝て待つ回のファイルは変えない）。直すのは、電池の大きさ・点線と「自分の分」の札（`MarginBattery`）・日めくりの「あと N日」の2段（`DaysLeftCalendar`）。看板（`MarginTable`）・カード（`../_shared/IssueCard`）・締め（寝て待つ回の `WaitEndCard` の形を写す）。色は `../_shared/theme`。
