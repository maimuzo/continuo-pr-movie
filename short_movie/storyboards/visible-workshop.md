# 見える工房の回　詳しいコンテ

**言いたいこと。**「continuo では、Claude Code が対話モードのまま pane の中で働き、その作業の内容を直接確認できる」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「見える工房の回」の表と注記、1節の共通の決まりが正で、構図と演技は絵コンテ `out/storyboards/visible_workshop/*.png` を見本にする。絵コンテと食い違うところ（別の端末の場面が無いことなど）はコンテが正。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。作りの見本は「置くだけの回」（[place_on_ready.md](place_on_ready.md)）である。

## 1. 共通の決まり

**言いたいこと。**場面ごとにカットを割り、ガラス張りの工房（herdr の pane）を、外から覗ける箱として描く。黒い箱と工房は同じ大きさにし、それぞれに看板を立てて、何と何を比べているかを字で示す。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| 工房 | `backgrounds/workshop` を中に置き、手前に濃い枠と、薄い水色の板と斜めの光の筋を重ねてガラスに見せる | pane が「中が見える囲い」だと、ひと目で分かるようにする |
| 箱の大きさ | 黒い箱の正面と、場面3の工房（枠の外側）を、どちらも幅380×高さ540にし、床（y=780）に置く | 人間の指摘。大きさが違うと、同じ役目のものを比べていると読めない |
| 看板 | 黒い箱の上に灰色の板で「他のフレームワーク」、工房の上に橙の板で「continuo」。字は 52px の太字で、板から2本の脚を箱・工房の上の面へ下ろす | 人間の指摘。黒い箱が何を指すか分からなかった。字幕（50〜64px）と同じくらいに読め、左半分（幅540）に収まる大きさ |
| 役の分け方 | Codex に紙を渡すのは Claude Code。コンティは工房の外で「どうぞ」と示すだけ | storyboard.md の注記。continuo が Codex に直接渡すことはない |
| Codex の作業 | 隣の台で短く揺れて仕上げる所までにし、仕上げた紙を Claude Code に返す | storyboard.md の注記。映すのは「頼んで、受け取る」所まで |
| 名前の札 | Claude Code が初めて出たとき（5.95秒）に札を1.5秒。2体が並ぶ場面4では、2体とも札を場面の間ずっと出す。Codex の札は青紫 #7A9DFF | 1節の決まりと人間の指示。形が同じ2体を色だけで見分けさせない |
| 開発者の顔 | 丸い輪郭と眼鏡の奥の大きな瞳。ガラスに顔を押し付けず、一歩離れて笑顔で見る。絵を伸び縮みさせない | 人間が「顔がかわいくない」と指摘した |
| 字幕 | 画面の下に1行。文言は storyboard.md の表のとおり。字の大きさは1行に収まる中でいちばん大きく、場面2は 64px、場面3は 50px、場面4は 42px | 無音で見られるため。64px のままでは場面3・4の字幕が2行に折れる |
| 締め | 13.0秒の1コマ目から「何してるか、いつでも見える」。下に「continuo」と URL、コンティ | 1節の締めの決まり |
| 別の端末 | 入れない | storyboard.md の注記。別の端末から覗けるのは Claude Code 自体の機能で、continuo の機能ではない |

### カット

| カット | 使う場面 | 配置 |
| --- | --- | --- |
| 黒い箱の部屋（Remotion で壁と床を塗る） | 場面2、場面3の左半分 | 左に開発者、右の床に黒い箱。場面3では左へ寄せて箱だけを左半分に収める |
| ガラスの工房（外から・同じ大きさ） | 場面3の右半分 | 工房を右に、その左下の外にコンティ |
| ガラスの工房（外から・大きく） | タイトル・場面4 | 工房を右に大きく。外の左に開発者とコンティ |

## 2. 場面ごとの作り（0〜9秒）

**言いたいこと。**前半は「中が見えない他のフレームワークの黒い箱」と「中が見える continuo の工房」を、同じ大きさで左右に並べて比べる。秒は動画の頭からの秒である。

### 場面1　タイトル（0〜2秒）

ガラスの工房のカットを、キャラクター無しでぼかして映し、手前に「見えるから、安心」。1.7秒から縮んで消える。

### 場面2　黒い箱（2〜5.5秒）

| 項目 | 中身 |
| --- | --- |
| 黒い箱 | 正面は x=560〜940。2.1秒から床の上でガタガタ揺れ、上の左右の端から灰色の煙を0.5秒ごとに吹く。揺れの線を左右に付ける |
| 看板 | 2.0秒の1コマ目から、箱の上に「他のフレームワーク」。箱と一緒に少し揺れる |
| 開発者 | 箱の左に立ち、マグを持ち、指をあごに当てて首をかしげる（ゆっくり左右に傾く）。2.6秒と4.0秒に頭の上へ「？」 |
| 字幕 | 「裏で何してるか、分からない？」 |

### 場面3　作業の内容を直接確認できる（5.5〜9秒）

| 項目 | 中身 |
| --- | --- |
| 画面の割り | 5.5〜5.9秒：黒い箱の部屋が左へ寄って箱が左半分（正面 x=80〜460）に収まり、少し暗くなる。開発者は画面の外へ出る。右半分に工房の部屋が右から滑り込む。間に太い仕切り |
| 工房 | 画面の x=660〜1040、y=240〜780。黒い箱の正面と同じ大きさ。中で Claude Code が作業台の奥で揺れながら作る |
| 看板 | 5.95秒に、工房の上に「continuo」が起き上がる |
| 名前の札 | 5.95〜7.45秒に、Claude Code の頭の上にテラコッタの札 |
| コンティ | 工房の左下の外に、右向きに浮かぶ。6.9秒にヒレを前へ出して「どうぞ」の吹き出しとキラリ |
| 吹き出し | 7.45秒から、考え事の吹き出しに「テストを書いて…」「ここを直そう」が1文字ずつ出る |
| 字幕 | 「continuo なら作業の内容を直接確認可能」 |

## 3. 場面ごとの作り（9〜15秒）

**言いたいこと。**後半は、工房の中で Claude Code が Codex に頼んで受け取り、2体でハイタッチする所までを、4秒かけてゆっくり見せる。

### 場面4　Claude Code が Codex に頼む（9〜13秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | ガラスの工房を右に大きく。中の左の台に Claude Code、右の台に Codex。外の左に開発者（ガラスから一歩離れて立つ）と、その上にコンティ |
| 名前の札 | 9.1秒から場面の終わりまで、2体の頭の上に「Claude Code」「Codex」 |
| 頼む | 9.4〜10.0秒：Claude Code が両手で紙を差し出し、紙が Codex の手へ飛ぶ |
| 仕上げる | 10.1〜11.1秒：Codex が隣の台で揺れて仕上げる。11.1秒：紙に赤い丸、キラリ |
| 返す・ハイタッチ | 11.25〜11.7秒：紙が Claude Code へ戻る。11.8秒：2体が片手を上げて寄り、12.0秒にハイタッチ（パチンの線とキラリ）。13秒まで2体が並んだまま |
| 開発者 | 笑顔でマグを持ってガラス越しに見ている。ハイタッチで「！」 |
| 字幕 | 「Claude Code がしていることは、そのまま見える」 |

### 場面5　締め（13〜15秒）

無地の背景に「何してるか、いつでも見える」、下に「continuo」と `github.com/maimuzo/continuo`、コンティが跳ねる。

## 4. 要る絵の一覧

**言いたいこと。**新しく描いた絵は開発者3枚と Claude Code 1枚で（うち `dev_tablet` は今は使っていない）、Codex の3枚は Claude Code の絵を塗り替えて作った。どれも `public/ep/visible_workshop/` に置く。

| 絵 | 中身 | 作り方 |
| --- | --- | --- |
| `dev_puzzled` | 立って右を向き、マグを持ち、指をあごに当てて首をかしげる | Codex。参照は `assets/ref/developer.png` |
| `dev_watch` | 立って右を向き、両手でマグを持って笑顔で見る | 同上 |
| `dev_tablet` | ソファに座り、白い画面のタブレットを掲げて笑う | 同上。別の端末の場面を外したので、今は使っていない |
| `cc_highfive` | 右を向き、片手を高く上げてハイタッチする Claude Code | Codex。参照は `assets/ref/claude_code.png` |
| `codex_receive`・`codex_work`・`codex_highfive` | Codex の受け取る・作る・ハイタッチ | `claude_code/receive`・`work` と `cc_highfive` を `out/work/visible_workshop/recolor_codex.py` で青紫に塗り替え |

**Codex の絵は塗り替えで作る。**characters.md のとおり2体は同じ型で、色だけが違うためである。口の中と頬と瞳は塗り替えから外す。
**黒い箱・煙・ガラス・看板・吹き出し・紙は Remotion で描く。**同じ線の太さと平らな塗りにそろえる。
**新しい効果音は2つ。**`visible_workshop_rattle`（黒い箱のガタガタ）と `visible_workshop_clap`（ハイタッチ）を `scripts/sfx_visible_workshop.py` で合成した。
