# Direct Chat の回　詳しいコンテ

**言いたいこと。**「ふだんは issue のコメントで Claude Code と会話している。込み入ったらカードを `Direct Chat` 列へ動かし、Claude Code と直接話せる。戻せば、またコメントで」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「Direct Chat の回」の表と1節の共通の決まりが正である。絵コンテ `out/storyboards/direct_chat/*.png` は前の筋（continuo がメガホンで指示する）のときのもので、構図の見本としてだけ使う。
キャラクターは [docs/spec/characters.md](../characters.md) にある。この回に Codex は出ない。作りの見本は「置くだけの回」（[place_on_ready.md](place_on_ready.md)）である。

## 1. 共通の決まり

**言いたいこと。**Claude Code への指示になるのは issue のコメントで、continuo ではない。だからコンティは指示を出す絵にせず、横で見守るだけにする。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| カット | 作業台（コメント）→ 作業台（絡まる）→ カンバン（動かす）→ 作業台（話す）→ カンバン（戻す）→ 作業台（またコメント）。カメラは動かさない | 場面ごとに構図を決めて端で切れないようにする |
| コンティ | 手を振る立ち絵（`continuo/wave`）だけを使う。メガホン・指示の紙・口のチャックは出さない | continuo は Claude Code を起動して見届けるだけで、指示を出さない（2026-10-29 に人間が示した） |
| コメント | 頭に書いた人の色の丸（開発者は紺、Claude Code はテラコッタ）と名前の線、本文の2行の白い札。文字は書かない | 15秒で文字を読ませず、誰から誰へのコメントかを色で見せる |
| カンバン | 6列（`Ready` / `In Progress` / `In Review` / `Blocked` / `Done` / `Direct Chat`）を 0.8倍で右寄りに掛ける。`Direct Chat` の見出しは紫 | 列の並びは continuo の README の Status の表のとおり。開発者の体がカードの左にあるので、右へ寄せないと左の端で切れる |
| カードを動かす開発者 | カンバンのカットの頭から、カードの前に立っている。左から歩いて入らない | 歩いて入ると、入りきるまで体が画面の左の端で切れる |
| Claude Code の顔 | 白い顔に琥珀色の目 | 設定画 `assets/ref/claude_code.png` のとおり |
| 字幕・名前の札 | 字幕は画面の下に1行で、文言は storyboard.md の表のとおり。名前の札は Claude Code が初めて出る2.15秒から1.6秒 | storyboard.md の1節の決まり |
| タイトル・締め | `src/videos/direct_chat/Cards.tsx`。締めは「話したいときは、」「直接」の2行 | 10文字の決めの字は、共通の大きさだと画面の幅を超えて切れる |

## 2. 場面ごとの作り（前半：0〜7秒）

**言いたいこと。**前半は、コメントで会話するふだんの様子と、コメントが絡まって `Direct Chat` へ動かすところである。秒は動画の頭からの秒である。

### 場面1　タイトル（0〜2秒）

作業台（コメント）のカットをぼかして映し、手前に「話したいときは、直接」。1.7〜2.0秒で縮んで消える。

### 場面2　issue のコメントで会話（2〜4.5秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 作業台のカット。左に作業台と、その奥で作る Claude Code。右に、膝のノートパソコンでコメントを書く開発者。上の真ん中でコンティが見守る |
| コメント | 2.3秒 開発者→Claude Code、2.85秒 Claude Code→開発者、3.4秒 開発者→Claude Code、3.95秒 Claude Code→開発者。弧を描いて0.45秒で届き、消える |
| 開発者 | コメントを送るたびに小さく弾む |
| 字幕 | 「ふだんは issue のコメントで会話」 |

### 場面3　込み入って Direct Chat へ（4.5〜7秒）

| 項目 | 中身 |
| --- | --- |
| 4.5〜5.6秒 | 同じ作業台のカット。コメントが0.12秒おきに6つ、2人の間へ降って傾いて積み上がる。4.95秒から黒い糸が山に絡まる。5.05秒に開発者が頭を抱え、汗が出る |
| 5.6〜7秒 | カンバンの壁のカット。`In Progress` のカードの前に開発者が立っている。5.8〜6.6秒にカードの左の縁に手を当て、一緒に右へ歩いて `Direct Chat` へ動かす。6.6秒に見出しが光り、きらり。6.3〜6.85秒にコンティが左下のクッションのそばへ下がる |
| 字幕 | 「込み入ってきたら、Direct Chat へ」 |

## 3. 場面ごとの作り（後半：7〜15秒）

**言いたいこと。**後半は、Claude Code の隣で直接話して山がほどけ、カードを戻すとまたコメントで会話に戻り、締めに決めの字を出すまでである。

### 場面4　Claude Code と直接話す（7〜10.5秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 作業台のカット。真ん中の上に壁の大きな画面（pane。ロゴは描かない）、その下に絡まったコメントの山。左に Claude Code、右に開発者。左下の隅でコンティが見守る |
| 開発者 | 7.0〜7.5秒：椅子ごと右から転がって Claude Code の隣へ寄る |
| 2人 | 2人とも画面を指さす。話す番が来た方が小さく弾む |
| 吹き出し | 7.7秒 開発者「？」→ 8.3秒 Claude Code「電球」→ 8.9秒 開発者「コード」→ 9.5秒 Claude Code「チェック」→ 10.0秒 開発者「きらり」 |
| コメントの山 | 最初の4つの話のたびに糸が4分の1ずつ消え、コメントが2列にきれいに並ぶ。9.8秒にほどけきってきらり |
| 字幕 | 「Claude Code と直接話せる」 |

### 場面5　戻せば、またコメントで（10.5〜13秒）

| 項目 | 中身 |
| --- | --- |
| 10.5〜11.4秒 | カンバンの壁のカット。`Direct Chat` のカードの前に開発者が立っていて、10.55〜11.0秒にカードを左へ引き戻す。`In Progress` の見出しが光る。10.85〜11.35秒にコンティがクッションから上へ戻る |
| 11.4〜13秒 | 作業台（コメント）のカット。開発者は席に戻り、Claude Code は作業を続け、コンティが上で見守る。11.7秒に Claude Code からコメントが1つ飛び、12.15秒にノートパソコンへ届く。12.25秒と12.53秒に開発者が頷き、きらり |
| 字幕 | 「戻せば、またコメントで」 |

### 場面6　締め（13〜15秒）

無地の背景に「話したいときは、」「直接」の2行、その下に小さく「continuo」と `github.com/maimuzo/continuo`、下にコンティ。13.0秒の1コマ目から字が見え、1.15倍から縮んで収まる。

## 4. 要る絵と音

**言いたいこと。**絵は Codex に緑の背景で描かせて `scripts/key_green.py` で抜き、`public/ep/direct_chat/` に置いた。元の絵は `out/work/direct_chat/` にある。

| 絵 | 中身 | 参照 |
| --- | --- | --- |
| `dev_laptop` | 椅子に座り、膝のノートパソコンでコメントを書く。左向き | `assets/ref/developer.png`、`characters/developer/typing` |
| `dev_tangle` | 同じ姿勢で、両手で頭を抱えて困る。顔は可愛いまま | 同上 |
| `dev_drag` | 立って右へ腕を伸ばし、手のひらでカードを押す。片手にマグカップ | `assets/ref/developer.png` |
| `dev_point` | 椅子に座り、左上を指さして話す | 同上 |
| `cc_point` | 右上を指さして話す。白い顔に琥珀色の目 | `assets/ref/claude_code.png` |

既存の絵は `backgrounds/workshop`・`corner`、`props/bench`、`characters/claude_code/work`、`characters/continuo/wave` を使う。
カンバン（6列）・コメントの札・コメントの山と糸・吹き出し・壁の画面は Remotion で描き、`src/videos/direct_chat/` に置く。
**音。**共通の音（typing・swish・pop・splat・sparkle）だけを使う。コメントが飛ぶと swish、届くと pop、山に積み上がると pop が続き、頭を抱えると splat、カードが列に着くと splat、山がほどけきると sparkle。
