# 止めても続きからの回　詳しいコンテ

**言いたいこと。**「continuo を `Ctrl+C` で止めても pane は閉じず、次に起動すれば続きから」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「止めても続きからの回」の表と注記、1節の共通の決まりが正で、構図は絵コンテ `out/storyboards/resume/{2-6,6-10,10-13}.png` を見本にする（秒の割り振りと夜・朝の流れはコンテが正）。
絵柄・字幕・締め・名前の札・効果音の付け方は、お手本の [置くだけの回](place_on_ready.md) にそろえる。

---

## 1. 共通の決まり

**言いたいこと。**全場面を「開発者の机とディスプレイ」の1つのカットで見せ、ロボットとクジラをディスプレイの窓の中で動かす。止まるのは左の窓だけで、夜に消すのはディスプレイの電源だけ、PC 本体のランプは最後まで点いたままにする。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| カット | 部屋の壁（`backgrounds/corner`）の前に、Remotion で描いた大きなディスプレイと机と、机の前の床に置いた PC 本体。左下に開発者。カメラは動かさない | 同じ画面を最後まで映せば、変わったのが窓の明暗とディスプレイの電源だけだと分かる |
| 窓 | ディスプレイの中に窓を2つ並べる。左は「continuo」の窓でコンティがいる。右は「pane：Claude Code」の窓で、机で作業する Claude Code がいる | storyboard.md の行のとおり。窓の題名で、どちらが continuo でどちらが pane かを字で補う |
| 窓の外に出さない | コンティも Claude Code も、自分の窓の中だけで動く（窓の外は切り取る）。渡す紙だけが窓の境目を越える | PC の中で動いている絵にするため |
| 止まった印 | 左の窓に暗い幕をかけ、題名の帯を灰色にする。コンティは目を開けたまま動きを止める。札は出さない。眠る絵は使わない | 暗くなるだけで止まったことは伝わる。眠る絵は、ほかの回で「continuo が動いたまま待っている」の意味に使っている |
| 電源 | ディスプレイは夜に電源が消えて画面が黒くなり、右下の灯りも消える。翌朝に点け直すと、右の窓は止める前のまま明るい。PC 本体のランプは全場面で緑に点いたまま、暗い部屋では光を強める | PC 本体の電源は切らない。消すのはディスプレイだけで、止めるのは continuo だけである |
| 夜と朝 | 4.9秒から部屋を青く暗くして「夜」の札と月を出す。7.0秒で明るい朝に戻して「翌朝」の札と太陽を出す | 時間が経ったことを、字幕を使わずに見せる |
| 開発者 | 座る絵は既存の左向きの絵を裏返してディスプレイを向かせる。帰る・出社するときは、かばんを持って歩く絵（帰りは裏返して左向き）。立っている間は空の椅子を描く。喜ぶときは笑顔でガッツポーズする絵。顔に弾みを付けない | characters.md の開発者は可愛い顔で、顔をつぶしたり歪めたりしない |
| 名前の札 | Claude Code が初めて出た2.1秒から1.5秒、右の窓の中の Claude Code の頭の上に浮かべる | 1節の決まり |
| 字幕 | 「continuo を止めても」（2〜5秒）、夜は字幕なし、「進行内容は、そのまま」（7〜10秒）、「次に起動すれば、続きから」（10〜13秒） | storyboard.md の字幕の列のとおり |
| 締め | 13.0秒から「止めても、消えない」と、continuo の名前と URL とコンティ | お手本と同じ |

## 2. 場面ごとの作り

**言いたいこと。**本編の4場面を storyboard.md の4行と1対1に対応させる。秒は動画の頭からの秒である。

| 場面 | 秒 | 中身 |
| --- | --- | --- |
| タイトル | 0〜2 | 止める前の画面をぼかして映し、「止めても、消えない」。1.7秒から縮んで消える |
| 止める | 2〜5 | 2.0秒：両方の窓が明るい。左でコンティが浮かび、右で Claude Code が机の奥で揺れて作る。2.5秒：開発者の手もとに大きな `Ctrl+C` のキーが出る。2.7秒：押す。左の窓だけが0.4秒で暗くなり、コンティは止まる。3.0秒〜：開発者はコーヒー。3.7秒：Claude Code が手元の作業を仕上げて拳を握る（きらり）。4.1秒〜：机の前に座って待つ |
| 夜 | 5〜7 | 4.9秒：部屋が夜になり「夜」の札と月。5.4秒：ディスプレイの電源が消えて画面が黒くなる（カチッ）。PC 本体のランプは緑に光ったまま。5.7秒：開発者がかばんを持って立つ。5.9〜6.7秒：左へ歩いて部屋を出る。空の椅子が残る |
| 翌朝 | 7〜10 | 7.0秒：部屋が朝になり「翌朝」の札。開発者がかばんを持って左から歩いてくる。7.6秒：席に着く。7.8秒：ディスプレイを点ける。右の窓では Claude Code が座ったまま待ち、左の窓は暗いまま。8.15〜8.85秒：暗い左の窓に `$ continuo` の字が出て Enter。8.95秒：左の窓が明るくなる。9.1秒：コンティが潮を吹いて跳ねる。9.45秒：窓の右の端へ寄る。9.65秒：Claude Code が立って両手を出す。9.7〜10.25秒：紙が窓の境目を越えて Claude Code の手へ渡る |
| 続きから | 10〜13 | 10.35秒：Claude Code が拳を握り、10.75秒から机の奥で作る（汗とスピード線）。コンティは左の窓でヒレを振る。10.5秒〜：開発者が椅子の横に立ち、笑顔でガッツポーズをして小さく跳ねて喜ぶ（きらり） |
| 締め | 13〜15 | 「止めても、消えない」、下に continuo と URL とコンティ |

**紙は窓の境目の上を飛ばす。**コンティが窓から出ずに渡せるうえ、「continuo が pane の Claude Code に次の指示を送る」ことを1枚の紙で見せられるためである。

## 3. 要る絵の一覧

**言いたいこと。**新しく描いたのは3枚（座って待つ Claude Code、かばんを持って歩く開発者、ガッツポーズで喜ぶ開発者）で、残りは既存の絵と Remotion の部品である。

| 絵 | 中身 | 作り方 |
| --- | --- | --- |
| `ep/resume/cc_sit_wait` | 床に座り、両手をひざに置いて目を開けたまま待つ Claude Code | Codex。参照は `assets/ref/claude_code.png` と `claude_code/wake` |
| `ep/resume/dev_walk_bag` | かばんを肩にかけて右へ歩く開発者。穏やかな笑顔 | Codex。参照は `assets/ref/developer.png` と `ep/flat_rate/dev_carry` |
| `ep/resume/dev_cheer` | 右を向いて立ち、片手を突き上げてガッツポーズする笑顔の開発者 | Codex。参照は `assets/ref/developer.png` と `developer/typing` |
| 既存 | `continuo/wave`・`leap`、`claude_code/work`・`fist`・`receive`、`developer/typing`・`sip_coffee`、`backgrounds/corner`・`workshop`、`props/bench` | そのまま |

**Remotion で描くもの。**ディスプレイ・窓の枠と題名の帯・暗くなる幕・黒い画面・PC 本体とランプ・空の椅子・`Ctrl+C` と Enter のキー・`$ continuo` の字・机・「夜」と「翌朝」の札。
**効果音。**既存の音に加え、`scripts/sfx_resume.py` で「止まる音」「点く音」「電源のカチッ」「足音」を作り、`public/sfx/resume_{off,on,click,steps}.wav` に置く。
