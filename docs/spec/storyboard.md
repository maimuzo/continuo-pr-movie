## 6. チームで入札の回　チームの continuo どうしで入札し、いちばん余裕のある人が担当する

チームの部屋に、メンバーの机（機械）が3つ並ぶ。どの机にも Claude Code が1体ずつ座り、その頭の上に、その機械のレートリミットの余裕を示す電池が浮かんでいる。コンティは1頭で、共有のカンバンの前に浮かんでいる。

| 秒 | 何が起きるか | 字幕 |
| --- | --- | --- |
| 0〜2 | タイトル。共有のカンバンに、カードが次々と `Ready` に積まれていく | — |
| 2〜6 | 新しいカードが1枚出るたびに、3体の Claude Code の電池にレートリミットの余裕値（72%・35%・10%）が浮かぶ（入札）。コンティがいちばん数字の大きい机へカードを運ぶ | レートリミットの余裕値で入札 |
| 6〜10 | 早回し。カードを取った机は電池が減り、次は別の机へカードが運ばれる。カードはいちばん余裕のある机へ流れ続ける。電池が空の机の Claude Code は、座ったまま待っている | 一番余裕のある人が担当 |
| 10〜13 | 3つの机が作業を分け合い、`In Review` 列が一気に埋まる | チームで作業分担 |
| 13〜15 | 締め「チームの余力を戦力へ」 | — |

continuo の README の「複数の機械で1枚のカンバンを共有でき、残っているレートリミットで入札し、いちばん余裕のある機械がその issue を取る」と食い違わないように作ってある。レートリミットの余裕を持つのは Claude Code の側なので、％の数字は Claude Code の電池に出す。コンティを3頭にすると、コンティがレートリミットを持っているように見えるため、1頭にした（2026-10-29 に人間が決めた）。実際には機械ごとに continuo が動いて入札するが、15秒では「いちばん余裕のある Claude Code へ渡る」ことだけを見せる。Codex は出さない。

## 7. 寝て待つ回　レートリミットが尽きても、待つか引き継ぐかで止まらない

**チームで入札の回のあとに置く。**1週間のレートリミットが尽きたときの引き継ぎは、チームで入札の回の入札を知っていると読み取れるためである。部屋と机3つ・電池・コンティ1頭は、チームで入札の回と同じにする。Claude Code の頭の上には電池を2本並べ、それぞれに「5時間」「1週間」の札を付ける。

| 秒 | 何が起きるか | 字幕 |
| --- | --- | --- |
| 0〜2 | タイトル「尽きても、勝手に再開」 | — |
| 2〜4 | 真ん中の机の Claude Code が猛烈に作業し、「5時間」の電池がみるみる減って空になる。Claude Code は手を止めて座り込む | 5時間のレートリミットが尽きても |
| 4〜7 | 壁の時計が早回しになる。リセットの時刻に針が届いた瞬間ベルが鳴り、「5時間」の電池が満タンへ戻る。Claude Code が立ち上がり、同じカードの続きを始める。誰も何もしていない | 放っておけば、勝手に再開 |
| 7〜10 | 日めくりが何枚もめくれる。今度は「1週間」の電池が空になる。カードに付いていた担当者の顔のアイコンが外れて落ち、カードがカンバンの `Ready` 列へ戻る | 1週間のレートリミットが尽きたら |
| 10〜13 | 残りの2つの机の Claude Code の電池に余裕値（68%・20%）が浮かぶ（入札）。コンティがそのカードを 68% の机へ運び、担当者のアイコンがその机の顔に替わる。その机の Claude Code が続きを引き継いで作り始める | 担当を外して、別の人が引き継ぐ |
| 13〜15 | 締め「尽きても、止まらない」 | — |

5時間のレートリミットは時間がたてば戻るので、continuo は待って同じ机で続ける（continuo の README の「使い切ったら待ち、戻ったら自分で続きを拾う」の段）。1週間のレートリミットは何日も戻らないので、担当を外して入札にかけ直し、別の人の机が引き継ぐ（2026-10-29 に人間が示した動き）。この回では「枠」という言葉を使わず、「レートリミット」と書く。

## 10. 止めても続きからの回　止めても、次に起動すれば続きから

## 13. セットアップの回　依存物を入れて、continuo を起動するまで

**言いたいこと。**入れるものとコマンドの順番を、端末の画面で見せる。macOS と Ubuntu で操作が違うところだけ、画面を左右に分ける。字幕は場面の見出しにし、コマンドそのものは端末の中に打ち込まれる字で見せる。

**この回だけ尺を30秒にする。**入れるものとコマンドが多く、15秒では2〜6秒のコマンドが読み切れなかったためである（2026-10-29 に人間が決めた）。1行のコマンドは、打ち終わってから次の行を打ち始めるまで1秒以上見せる。場面の頭に端末が `$` だけになる間を作らない。
