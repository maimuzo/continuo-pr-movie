# Direct Chat の回　詳しいコンテ

**言いたいこと。**「カードを `Direct Chat` 列へ動かすと、continuo は黙り、人間が Claude Code と直接話せる。戻せば continuo がまた指示を出す」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「Direct Chat の回」の表と1節の共通の決まりが正で、構図と演技は絵コンテ `out/storyboards/direct_chat/{2-5,5-8,8-12,12-13}.png` を見本にする。
キャラクターは [docs/spec/characters.md](../characters.md) にある。この回に Codex は出ない。作りの見本は「置くだけの回」（[place_on_ready.md](place_on_ready.md)）である。

---

## 1. 共通の決まり

**言いたいこと。**絵柄・字幕・名前の札・締めは置くだけの回にそろえ、この回だけの違いは6列のカンバンと、長い決めの字を収めることである。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| カット | 作業台・カンバンの壁・作業台（話す）・カンバンの壁（戻す）の4つを切り替える。カメラは動かさない | 置くだけの回と同じく、場面ごとに構図を決めて端で切れないようにする |
| カンバン | 6列（`Ready` / `In Progress` / `In Review` / `Blocked` / `Done` / `Direct Chat`）を 0.8倍で右寄りに掛ける。`Direct Chat` の見出しは紫 | 列の並びは continuo の README の Status の表のとおり。開発者の体がカードの左にあるので、カンバンを右へ寄せないと開発者が左の端で切れる |
| Claude Code の顔 | 白い顔に茶色（琥珀色）の目。黒い画面の顔にしない | 設定画 `assets/ref/claude_code.png` のとおり。絵コンテの 2-5.png は顔が黒くなっていて誤り |
| 字幕 | 画面の下に1行。文言は storyboard.md の字幕の列のとおり | 無音で見られるため |
| 名前の札 | Claude Code が初めて出る2.15秒から1.6秒、頭の上にテラコッタの札 | storyboard.md の1節の決まり |
| 吹き出し | 中は文字でなく、問い・電球・コード・チェック・きらりの記号 | 15秒で文字を読ませず、会話が進むことだけを伝える |
| タイトル・締め | 共通の部品を `src/videos/direct_chat/Cards.tsx` に写し、字を小さくする。締めは「話したいときは、」「直接」の2行 | 10文字の決めの字は、共通の大きさだと画面の幅を超えて切れる |

**コンティの口のチャックとメガホンで、continuo が指示を送らないことを見せる。**README の `Direct Chat` の説明（continuo は何も送らず、人間が pane で直接話す）を、字の説明なしで伝えるためである。

## 2. 場面ごとの作り（前半：0〜8秒）

**言いたいこと。**前半は、ふだんコンティがメガホンで指示を出している様子と、カードを `Direct Chat` へ動かすとコンティが黙るところである。秒は動画の頭からの秒である。

### 場面1　タイトル（0〜2秒）

作業台のカットをぼかして映し、手前に「話したいときは、直接」。1.7〜2.0秒で縮んで消える。

### 場面2　コンティがメガホンで指示（2〜5秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 作業台のカット。右に作業台と、その奥で揺れながら作る Claude Code。左上にメガホンを構えたコンティ |
| コンティ | 2.3・2.9・3.5・4.1秒にメガホンで叫び、そのたびに少し前へ乗り出す。口から音の弧が出る |
| 指示の紙 | 叫ぶたびに、矢印・足す・行・チェックの記号の紙が1枚、弧を描いて Claude Code の頭へ飛び、0.5秒で届いて消える |
| Claude Code | ずっと小刻みに揺れて作る。汗とスピード線 |
| 字幕 | 「ふだんは continuo が指示」 |

### 場面3　Direct Chat へ動かすと、コンティが黙る（5〜8秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | カンバンの壁のカット。`In Progress` にカードが1枚。左上にメガホンを持ったコンティ |
| 開発者 | 5.0〜5.4秒：左から歩いて入る。5.5〜6.5秒：カードの左の縁に手を当て、カードと一緒に右へ歩いて `Direct Chat` へ動かす |
| カンバン | 6.5秒：`Direct Chat` の見出しが光り、きらり。動かしているあいだは押しピンを外す |
| コンティ | 6.55秒：びっくりマーク。6.8秒：メガホンを放し、メガホンは床へ落ちて小さく跳ねる（7.05秒）。7.2秒：口にチャック（黄色いジグザグが走る）。7.35〜7.85秒：左下のクッションのそばへ下がる |
| 字幕 | 「Direct Chat に動かすと」 |

## 3. 場面ごとの作り（後半：8〜15秒）

**言いたいこと。**後半は、開発者が Claude Code の隣で話し、カードを戻すとコンティがメガホンを拾い直し、締めに決めの字を出すまでである。

### 場面4　Claude Code と直接話す（8〜12秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 作業台のカット。真ん中の上に壁の大きな画面（pane。ロゴは描かない）。左に Claude Code、右に開発者。左下の隅に、口にチャックをしたコンティと置いたメガホン |
| 開発者 | 8.0〜8.5秒：椅子ごと右から転がって Claude Code の隣へ寄る |
| 2人 | 2人とも画面を指さす。話す番が来た方が小さく弾む |
| 吹き出し | 8.7秒 開発者「？」→ 9.3秒 Claude Code「電球」→ 9.9秒 開発者「コード」→ 10.5秒 Claude Code「チェック」→ 11.1秒 開発者「きらり」 |
| 画面 | 話が進むにつれて行が増え、10.5秒に最後の行がチェックになる |
| 字幕 | 「Claude Code と直接話せる」 |

### 場面5　戻せば、また continuo が（12〜13秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | カンバンの壁のカット。カードは `Direct Chat` にある。コンティはクッションのそばで口にチャック |
| 開発者 | 12.0〜12.45秒：カードの左の縁に手を当てたまま左へ歩き、`In Progress` へ引き戻す。`In Progress` の見出しが光る |
| コンティ | 12.5秒：チャックを外し、メガホンを拾って高く掲げ、潮を吹く。きらり |
| 字幕 | 「戻せば、また continuo が」 |

### 場面6　締め（13〜15秒）

無地の背景に「話したいときは、」「直接」の2行、その下に小さく「continuo」と `github.com/maimuzo/continuo`、下にコンティ。13.0秒の1コマ目から字が見え、1.15倍から縮んで収まる（1.5倍からだと1行目が端で切れる）。

## 4. 要る絵と音

**言いたいこと。**新しく描いた絵は7枚で、どれも Codex に緑の背景で描かせて `scripts/key_green.py` で抜き、`public/ep/direct_chat/` に置いた。元の絵は `out/work/direct_chat/` にある。

| 絵 | 中身 | 参照 |
| --- | --- | --- |
| `konti_megaphone` | 右向きに浮かび、メガホンで叫ぶ | `assets/ref/continuo.png` |
| `konti_zip` | 右向き、口にチャック、ヒレを下ろして控える | 同上 |
| `konti_cheer` | 右向き、メガホンを高く掲げて喜ぶ。潮を吹く | 同上 |
| `megaphone` | 横に倒れたメガホン（白に赤） | 同上 |
| `dev_drag` | 立って右へ腕を伸ばし、手のひらでカードを押す。片手にマグカップ | `assets/ref/developer.png` |
| `dev_point` | 椅子に座り、左上を指さして話す | 同上 |
| `cc_point` | 右上を指さして話す。白い顔に琥珀色の目 | `assets/ref/claude_code.png` |

既存の絵は `backgrounds/workshop`・`corner`、`props/bench`、`characters/claude_code/work`、`characters/continuo/wave` を使う。
カンバン（6列）・指示の紙・音の弧・チャックの印・吹き出し・壁の画面は Remotion で描き、`src/videos/direct_chat/` に置く。
**音。**共通の音に加え、メガホンの「ブッ」（`direct_chat_blare`）とチャックの「ジーッ」（`direct_chat_zip`）を `scripts/sfx_direct_chat.py` で合成した。
