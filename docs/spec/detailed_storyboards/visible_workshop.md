# 見える工房の回　詳しいコンテ

**言いたいこと。**「continuo では、Claude Code が対話モードのまま pane の中で働く様子が、いつでも・どの端末からでも見える」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「見える工房の回」の表と注記、1節の共通の決まりが正で、構図と演技は絵コンテ `out/storyboards/visible_workshop/{2-5,5-8,8-11,11-13}.png` を見本にする。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。作りの見本は「置くだけの回」（[place_on_ready.md](place_on_ready.md)）である。

---

## 1. 共通の決まり

**言いたいこと。**場面ごとにカットを割り、ガラス張りの工房（herdr の pane）を、外から覗ける箱として描く。役の分け方は「Claude Code が Codex に頼む。コンティは工房の外」を守る。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| 工房 | `backgrounds/workshop` を中に置き、手前に濃い枠と、薄い水色の板と斜めの光の筋を重ねてガラスに見せる | pane が「中が見える囲い」だと、ひと目で分かるようにする |
| 役の分け方 | Codex に紙を渡すのは Claude Code。コンティは工房の外で「どうぞ」と示すだけ | storyboard.md の注記。continuo が Codex に直接渡すことはない |
| Codex の作業 | 隣の台で短く揺れて仕上げる所までにし、仕上げた紙を Claude Code に返す | storyboard.md の注記。映すのは「頼んで、受け取る」所まで |
| 名前の札 | Claude Code が初めて出たとき（5.5秒）に札を1.5秒。2体が並ぶ場面4（8〜11秒）では、2体とも札を場面の間ずっと出す。Codex の札は青紫 #7A9DFF | 1節の決まりと人間の指示。形が同じ2体を色だけで見分けさせない |
| 開発者の顔 | 丸い輪郭と眼鏡の奥の大きな瞳。ガラスに顔を押し付けず、一歩離れて笑顔で見る。絵を伸び縮みさせない | 人間が「顔がかわいくない」と指摘した |
| 字幕 | 画面の下に1行。文言は storyboard.md の表のとおり。場面4の字幕は長いので 42px にする | 無音で見られるため。64px のままでは場面4の字幕が2行に折れる |
| 締め | 13.0秒の1コマ目から「何してるか、いつでも見える」。下に「continuo」と URL、コンティ | 1節の締めの決まり |

### カット

| カット | 使う場面 | 配置 |
| --- | --- | --- |
| 黒い箱の部屋（Remotion で壁と床を塗る） | 場面2・場面3の左 | 左に開発者、右の床に黒い箱 |
| ガラスの工房（外から） | タイトル・場面3の右・場面4 | 工房を右に大きく。外の左に開発者とコンティ |
| 居間（`backgrounds/room`） | 場面5 | ソファの開発者がタブレットを持つ。左上に PC の小窓 |

## 2. 場面ごとの作り（0〜8秒）

**言いたいこと。**前半は「中が見えない黒い箱」と「中が見えるガラスの工房」を、左右に並べて比べる。秒は動画の頭からの秒である。

### 場面1　タイトル（0〜2秒）

ガラスの工房のカットを、キャラクター無しでぼかして映し、手前に「見えるから、安心」。1.7秒から縮んで消える。

### 場面2　黒い箱（2〜5秒）

| 項目 | 中身 |
| --- | --- |
| 黒い箱 | 2.1秒から、床の上でガタガタ揺れ、上から灰色の煙を2〜3つずつ吹く。揺れの線を左右に付ける |
| 開発者 | 箱の左に立ち、マグを持ち、指をあごに当てて首をかしげる（ゆっくり左右に傾く）。2.6秒と3.8秒に頭の上へ「？」 |
| 字幕 | 「裏で何してるか、分からない？」 |

### 場面3　ガラス張り（5〜8秒）

| 項目 | 中身 |
| --- | --- |
| 画面の割り | 5.0〜5.4秒：場面2が左の幅340へ縮んで暗くなり、右の幅740にガラスの工房が右から滑り込む。間に太い仕切り |
| Claude Code | 工房の中、作業台の奥で揺れながら作る。5.5〜7.0秒に頭の上にテラコッタの札 |
| 吹き出し | 6.0秒から、考え事の吹き出しに「テストを書いて…」「ここを直そう」が1文字ずつ出る |
| コンティ | 工房の外の左。右向きに浮かび、6.3秒にヒレを前へ出して「どうぞ」の吹き出しとキラリ |
| 字幕 | 「continuo なら、ガラス張り」 |

## 3. 場面ごとの作り（8〜15秒）

**言いたいこと。**後半は、工房の中で Claude Code が Codex に頼んで受け取る所を見せ、別の端末からも同じ工房が見えることで締める。

### 場面4　Claude Code が Codex に頼む（8〜11秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | ガラスの工房を右に大きく。中の左の台に Claude Code、右の台に Codex。外の左に開発者（ガラスから一歩離れて立つ）と、その上にコンティ |
| 名前の札 | 8.1秒から場面の終わりまで、2体の頭の上に「Claude Code」「Codex」 |
| 頼む | 8.3〜8.9秒：Claude Code が両手で紙を差し出し、紙が Codex の手へ飛ぶ |
| 仕上げる | 9.0〜9.8秒：Codex が隣の台で揺れて仕上げる。9.8秒：紙に赤い丸、キラリ |
| 返す・ハイタッチ | 9.9〜10.3秒：紙が Claude Code へ戻る。10.35秒：2体が片手を上げて寄り、10.5秒にハイタッチ（パチンの線とキラリ） |
| 開発者 | 笑顔でマグを両手に持って見ている。ハイタッチで「！」 |
| 字幕 | 「Claude Code がしていることは、そのまま見える」 |

### 場面5　別の端末からも（11〜13秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 居間のソファで、開発者がタブレットを持つ。左上に、PC の画面の小窓（同じ工房） |
| 動き | 11.0秒：PC の小窓に、働く Claude Code。11.35秒：タブレットの画面が点いて、同じ工房と同じ動きの Claude Code が映る（小窓が1つ増える） |
| 字幕 | 「別の端末からも」 |

### 場面6　締め（13〜15秒）

無地の背景に「何してるか、いつでも見える」、下に「continuo」と `github.com/maimuzo/continuo`、コンティが跳ねる。

## 4. 要る絵の一覧

**言いたいこと。**新しく描いた絵は開発者3枚と Claude Code 1枚で、Codex の3枚は Claude Code の絵を塗り替えて作った。どれも `public/ep/visible_workshop/` に置く。

| 絵 | 中身 | 作り方 |
| --- | --- | --- |
| `dev_puzzled` | 立って右を向き、マグを持ち、指をあごに当てて首をかしげる | Codex。参照は `assets/ref/developer.png` |
| `dev_watch` | 立って右を向き、両手でマグを持って笑顔で見る | 同上 |
| `dev_tablet` | ソファに座り、白い画面のタブレットを掲げて笑う | 同上。白い画面の位置に Remotion で工房を重ねる |
| `cc_highfive` | 右を向き、片手を高く上げてハイタッチする Claude Code | Codex。参照は `assets/ref/claude_code.png` |
| `codex_receive`・`codex_work`・`codex_highfive` | Codex の受け取る・作る・ハイタッチ | `claude_code/receive`・`work` と `cc_highfive` を `out/work/visible_workshop/recolor_codex.py` で青紫に塗り替え |

**Codex の絵は塗り替えで作る。**characters.md のとおり2体は同じ型で、色だけが違うためである。口の中と頬と瞳は塗り替えから外す。
**黒い箱・煙・ガラス・吹き出し・紙は Remotion で描く。**同じ線の太さと平らな塗りにそろえる。
**新しい効果音は2つ。**`visible_workshop_rattle`（黒い箱のガタガタ）と `visible_workshop_clap`（ハイタッチ）を `scripts/sfx_visible_workshop.py` で合成した。
