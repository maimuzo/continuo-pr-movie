# 定額のままの回　詳しいコンテ

**言いたいこと。**「continuo は Claude Code をいつもの対話モードのまま動かすので、定額プランのままで従量課金にならない」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「定額のままの回」の表と1節の共通の決まりが正で、構図と演技は絵コンテ `out/storyboards/flat_rate/{2-6,6-10,10-13}.png` を見本にする。
絵コンテ `6-10` では右の Claude Code が泣き顔になっていて、右の意味が読み取れなかった（人間の指摘）。この文書では、右も左と同じレジ・同じだけの品・楽しそうに働く Claude Code にし、違いをレジの金額表示だけに絞る。

---

## 1. 共通の決まり

**言いたいこと。**左右を同じ作りに並べ、違いを「レジの数字が回るか止まるか」だけにする。違いが1つだけなら、無音でも右の意味が読める。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| 左右の分け方 | 2〜10秒は画面を縦に2つに割る。左は「ほかのやり方」、右は「continuo」の札を上に出す。間に太い線 | storyboard.md の「左半分」「右半分」。札が無いと、どちらが continuo か分からない |
| 半分の中の配置 | 右上にレジ、左に品を積む台、その手前に Claude Code、右手前に開発者。右半分では、レジと Claude Code の間にコンティが浮かぶ | 幅540に4つを並べると重なるので、レジと品の山を上の段に上げた |
| 左右でそろえるもの | 背景（作業台の部屋）・レジの形と大きさ・Claude Code の絵と動き・積み上げる品の数と速さ | 人間の指摘。違いが多いと、どこを見ればよいか分からない |
| 左右で違えるもの | レジの表示（左は回り続ける、右は「定額」の字のまま止まる）・引き出し（左は開いて硬貨が飛ぶ、右は閉じて錠）・開発者の顔（左は青ざめる、右はくつろぐ）・右にだけコンティ | この回で言いたいことそのもの |
| 計器の形 | 課金はレジの金額表示だけで見せる。電池の燃料計（利用枠）は出さない | storyboard.md の1節の「計器の形」 |
| Claude Code | 左右とも、品を頭の上に持ち上げて笑う絵と、作業台で手を動かす絵を交互に出す。泣き顔・汗にしない | 人間の指摘。右で泣くと「定額だと苦しい」と読めてしまう |
| レジ・硬貨・品 | Remotion で、太い線と平らな塗りで描く。数字は桁ごとの回転ドラムにする | 数字を絵にすると回せない。左は下の桁ほど速く回し、右は1コマも動かさない |
| 字幕 | 画面の下に1行。文言は storyboard.md の字幕の列のとおり。17字の「定額プランなら、従量課金にならない」だけ字を 56 にする | 64 では画面の幅を超える |
| 名前の札 | Claude Code が初めて出る 2.1秒から1.5秒、左の Claude Code の頭の上にテラコッタの札 | storyboard.md の1節の決まり |
| 締め | 13.0秒の1コマ目から「メーター、回りません」と、下に小さく「continuo」と `github.com/maimuzo/continuo`、その下にコンティ | お手本の置くだけの回と同じ |

**右のレジには金額を出さず、「定額」の字だけを出す。**金額を出すと、実際のプランの値段と取り違えられるためである。

## 2. 場面ごとの作り

**言いたいこと。**5つの場面に分け、本編の3場面（2〜13秒）を storyboard.md の3行と1対1に対応させる。秒は動画の頭からの秒である。

| 場面 | 秒 | 中身 |
| --- | --- | --- |
| 1 タイトル | 0〜2 | 左右に割った部屋をぼかして映し、手前に「定額のまま、回し続ける」。1.7〜2.0秒で縮んで消える |
| 2 左：従量課金 | 2〜6 | 左半分。Claude Code が0.5秒ごとに品を1つ持ち上げて山に積む。積むたびにレジの引き出しから硬貨が飛び、「チャリン」。表示の金額は ¥0 から回り始め、だんだん速く回る。開発者は 2.9秒に「！」、3.2秒から顔に青い縦線を出して青ざめ、汗を垂らす。右半分はシャッターが閉まっていて「？」 |
| 3 右：定額のまま | 6〜10 | 6.0〜6.35秒で右のシャッターが上がる。右にも左と同じレジ・同じ数の品の山・同じ動きの Claude Code。表示は「定額」の字で止まり、6.5秒に錠が上から落ちて引き出しに掛かる（「カチャ」）。Claude Code の頭の上をコンティが浮かび、ヒレを振る。開発者は椅子でコーヒーをすすり、湯気が立つ。左はそのまま回り続ける |
| 4 引っ越す | 10〜13 | 1つの部屋に切り替える。左に従量課金のレジ（回っている）、右に錠の掛かったレジと、品を積む Claude Code とコンティ。10.5秒に開発者がプラグを引き抜き（「プツッ」）、左の表示が消える。11.1秒から開発者が箱を抱えて右へ歩き、12.7秒に右の工房に着く |
| 5 締め | 13〜15 | 無地の背景に「メーター、回りません」。コンティがぴょんと跳ねる |

**2〜6秒のあいだも、右の品の山は裏で左と同じ数だけ積んでおく。**シャッターが上がった瞬間に、左と同じ高さの山が見え、「同じだけ働いている」と読めるためである。
**右の品を積むときは音を鳴らさない。**左だけ「チャリン」と鳴るので、音を出して見る人にも違いが伝わる。
