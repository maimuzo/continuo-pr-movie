# 詰まったらひとことの回　詳しいコンテ

**言いたいこと。**「Claude Code が行き詰まると、continuo がカードを `Blocked` へ移し、開発者がコメントでひとこと書いて `Ready` へ戻すと、続きから再開する」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「詰まったらひとことの回」の表と1節の共通の決まりが正で、構図と演技は絵コンテ `out/storyboards/blocked/{2-5,5-7,7-10,10-13}.png` を見本にする。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。continuo の役はクジラのコンティ、Claude Code の役はテラコッタ色の丸いロボットで、この回に Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**プロジェクトを積み木の工事現場として描き、「問題にぶつかる」を「道が壁でふさがれ、分かれ道の先が霧で見えない」に置き換える。壁に激突するだけの絵にはしない。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| 工事現場 | 積み木の家が並ぶ小さな工事現場。手前から奥へ道がのび、奥で壁に突き当たって左右に分かれる。左右の道の先は霧で見えない | 人間の指摘。Claude Code が作っている途中で、どちらへ進めばよいか分からなくなる、という詰まり方を見せる。壁に激突するだけでは「壊れた」に見える |
| 詰まった姿 | 頭に「？」を浮かべ、片手を挙げる。ピースにしない | 人間の指摘。挙げた手は「質問があります」の手で、喜んでいるようには見せない |
| `Ready` へ戻す人 | 開発者がマウスでカードを `Blocked` から `Ready` へ引きずって戻す | continuo の README の運用。continuo は `Blocked` へ移すだけで、戻すのは人間である |
| カンバン | 列は `Ready`（緑）/ `In Progress`（黄）/ `Blocked`（赤）/ `In Review`（青）/ `Done`（薄紫）。共通の部品を `src/videos/blocked/Kanban.tsx` に写して列を足した | 共通の部品には `Blocked` の列が無い。`Done` の赤と `Blocked` の赤が紛れないように、`Done` を薄紫にした |
| 霧 | Remotion で、白い丸を重ねた雲に太い輪郭線と影1段を付けて描く。背景の絵には描かない | 右の霧だけを晴らすので、背景とは別の部品にする。絵柄は設定画の平らな塗りにそろえる |
| 積み木 | 組み上げる積み木の家は Remotion で描く（太い輪郭線・平らな塗り・上に丸い突起） | 1個ずつ積み上がる動きを見せるため |
| 開発者の顔 | 丸い輪郭と、眼鏡の奥の大きな瞳。絵を伸び縮みさせる弾みを付けない | characters.md の開発者は可愛い顔で、顔をつぶしたり歪めたりしない |
| 字幕・名前の札・締め | お手本の置くだけの回と同じ部品と位置。Claude Code が初めて出た2.1秒から1.5秒、テラコッタの札を頭の上に浮かべる | storyboard.md の1節の決まり |
| タイトルと締めの字 | どちらも「詰まったら、ひとこと」の10文字なので、タイトルは92px、締めは96pxに下げる | 共通の大きさ（104px・150px）では、10文字が画面の端で切れる |

### カット

| --- | --- | --- |
| 工事現場（`ep/blocked/site`） | タイトル・場面2・場面5 | 手前中央から奥へ道。奥の中央に壁、その手前で道が左右に分かれる。左右の道に霧 |

## 2. 場面ごとの作り（前半：0〜7秒）

**言いたいこと。**6つの場面に分け、本編の4場面（2〜13秒）を storyboard.md の4行と1対1に対応させる。前半は、Claude Code が詰まって手を挙げ、コンティがカードを `Blocked` へ移すまでである。秒は動画の頭からの秒である。

### 場面1　タイトル（0〜2秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 霧のかかった工事現場を、キャラクター無しでぼかして映す。手前に大きくタイトル「詰まったら、ひとこと」 |
| 動き | 1.7〜2.0秒でタイトルが縮んで消える |

### 場面2　組み上げる途中で、道がふさがれて詰まる（2〜5秒）

| 項目 | 中身 |
| --- | --- |
| Claude Code | 2.0〜2.6秒：道の手前で積み木を頭の上に持ち上げ、道の左わきの塔へ放って3段目を積む（2.6秒に積み上がる）。2.6〜3.55秒：次の部品を抱え、背中を見せて奥へ走る。奥へ行くほど小さくする。3.55秒：壁の前で突き当たり、少し跳ね返る。3.85秒〜：振り向き、片手に積み木を抱えたまま、もう片方の手を挙げる（ピースにしない）。4.0秒〜：頭の横に大きな「？」と汗 |
| 霧 | 左右の道の上に霧の塊を置き、それぞれに薄い「？」を浮かべる。どちらへ進めばよいか見えないことを示す |
| 名前の札 | 2.1〜3.6秒。走るあいだも頭の上について動く |
| 効果 | 積み上がるときに「くしゃ」の線。走り出しにスピード線。突き当たったときに「くしゃ」の線と星 |
| 字幕 | 「行き詰まったら」 |

**壁は「ぶつかって壊れる」ではなく「道の先をふさぐもの」として描く。**突き当たりの演技は短い跳ね返りだけにし、見せ場は振り向いて手を挙げる姿に置く。

### 場面3　コンティが `Blocked` へ移し、開発者が気づく（5〜7秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | カンバンの壁のカット。`In Progress` にこの回のカードがある |
| コンティ | 5.0〜5.45秒：左の外から右向きに浮かんで来る。5.45〜5.95秒：前ヒレの先でカードを `Blocked` へ押す |
| カンバン | 5.95秒：`Blocked` の見出しが光り、カードのまわりで赤い輪が脈打つ |
| 開発者 | 5.4〜5.8秒：右の外から入り、マグカップを持ったまま左上のカンバンを見上げる。6.1秒：集中線とびっくりマーク |
| 字幕 | 「continuo が Blocked に」 |

## 3. 場面ごとの作り（後半：7〜15秒）

**言いたいこと。**後半は、開発者がコメントで「右だよ」と書いてカードを `Ready` へ戻し、それが届いて右の霧が晴れ、Claude Code がその先の家を組み上げるまでである。

### 場面4　コメントでひとこと書き、`Ready` へ戻す（7〜10秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 机のカット。左上にノートパソコンの画面を大きく浮かべる。右で開発者が打つ |
| 画面（前半） | issue の画面。`#42` と赤い `Blocked` の札、コンティのコメント（灰色の行）。7.2〜7.85秒：コメント欄に「右だよ」が1字ずつ入る。8.05秒：送るボタンが沈み、「右だよ」が吹き出しになってやりとりに加わる |
| 画面（後半） | 8.6秒：画面が Projects のカンバンに切り替わる。9.0秒：マウスの矢印が `Blocked` のカードをつかみ、9.0〜9.5秒に `Ready` へ引きずる。点線の矢印で向きを示す。9.5秒：`Ready` の見出しが光る |
| 字幕 | 「コメントでひとこと」 |

**`Ready` へ戻すのは開発者のマウスである。**1節の決まりのとおり、コンティはこの場面に出さない。

### 場面5　ひとことが届き、右の霧が晴れて再開する（10〜13秒）

| 項目 | 中身 |
| --- | --- |

| Claude Code | 10.75秒：「？」が「！」ときらりに変わる。11.35〜11.95秒：積み木を抱えて右の道を走る。11.95秒〜：空き地の前で積み木を頭の上に持ち上げる |

## 4. 要る絵と音

**言いたいこと。**新しく描いた絵は、工事現場の背景1枚と、Claude Code 4枚、開発者1枚である。ほかは既存の絵を使う。

| 絵 | 中身 | 使う場面 | 作り方 |
| --- | --- | --- | --- |
| `ep/blocked/site` | 積み木の工事現場。手前から奥への道、奥の赤い壁、左右に分かれる道、両わきの家、右の道の先の空き地 | 1・2・5 | Codex。霧は描かせない |
| `ep/blocked/cc_place` | 積み木を両手で頭の上に持ち上げる | 2・5 | Codex。参照は `assets/ref/claude_code.png`。緑の積み木が混ざった1枚目は抜けないので描き直した |

| `ep/blocked/cc_confused` | 困った顔で、積み木を片腕に抱え、もう片方の手のひらを挙げる | 2・5 | 同上。ピースにしないと指定した |
