# 寝て待つ回　詳しいコンテ

**言いたいこと。**「利用枠を使い切っても continuo は待ち、枠が戻ったら勝手に続きから再開させる」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「寝て待つ回」の表と1節の共通の決まりが正で、構図と演技は絵コンテ `out/storyboards/wait_quota/{2-5,5-8,8-11,11-13}.png` を見本にする。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。continuo の役はクジラのコンティ、Claude Code の役はテラコッタ色の丸いロボットで、この回に Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**利用枠は Claude Code の頭の上の電池の形の燃料計で見せ、残りと時刻はカットをまたいで滑らかにつなぐ。眠るコンティは「continuo が動いたまま待っている」の意味で見せる。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| カット | 作業台（2〜5秒・12.05〜13秒）と部屋の隅（5〜12.05秒）の2つ。カメラは動かさない | 座り込む・寝て待つには床が要る。作業台の奥では下半身が台に隠れる |
| 燃料計 | 電池の形。白い本体と端子、中身は黄色（#F2C14E）に影1段。空になると枠が赤く点滅し、中に「！」 | 1節の「計器の形」。課金のレジの表示と取り違えないため。緑は抜き色なので使わない |
| 残りと時刻 | 動画の頭からの秒の関数で決める（`fuelAt`・`clockAt`） | カットが替わっても、燃料計と時計の針が飛ばない |
| 夜の暗さ | 空になった 5.35秒から薄い藍色を重ね、ベルの 9.6秒で消す。燃料計と壁の時計は暗さの上にもう一度描く | 待っている時間を見せる。暗くしても計器は読めるようにする |
| 眠るコンティ | 目覚まし時計を抱えて、泡と「Z」を出して眠る | 止まっているのではなく、時刻を見張りながら待っていることを示す |
| 名前の札 | Claude Code が初めて出た 2.1〜3.6秒、頭の上にテラコッタの札。燃料計はそのあいだ札の上に置き、札が消えたら頭のすぐ上へ下ろす | 1節の決まり。札と燃料計を重ねないため |
| 字幕 | 場面の頭から4フレーム後に1行。文言は storyboard.md のとおり | お手本の置くだけの回にそろえる |
| 締め | 「尽きたら寝て待つ」を 112px で、13.0秒の1コマ目から出す。下に「continuo」と URL、眠るコンティ | 8文字あり、共通の EndCard の 150px では画面からはみ出す。そのため `src/videos/wait_quota/WaitEndCard.tsx` に写して字を小さくした |

## 2. 場面ごとの作り

**言いたいこと。**本編の4場面を storyboard.md の4行と1対1に対応させる。秒は動画の頭からの秒である。

| 秒 | 場面 | 中身 |
| --- | --- | --- |
| 0〜2 | タイトル | 作業台のカットをぼかし、手前に「尽きても、勝手に再開」。1.7秒から縮んで消える |
| 2〜5 | 作業する | 作業台の奥で Claude Code がだんだん激しく揺れて作る。汗とスピード線。燃料計は満タンから、減り方を速めながら 15% まで減り、黄色の粒がこぼれ落ちる。字幕「作業の途中で」 |
| 5〜8 | 空になる | 部屋の隅のカット。5.0〜5.35秒：立ったままの Claude Code の燃料計が 0 になり、赤く点滅。5.55秒：座り込み、がっくりの線。左下のクッションで、コンティが目覚まし時計を抱えて眠る。右上の壁の時計は9時。字幕「枠を使い切っても」 |
| 8〜11 | 寝て待つ | 8.1秒：壁の時計の横に早回しの印（黄色の ▶▶）、分針が残像を引いて回り、短針が9時から12時の赤い印へ進む。9.6秒：12時に届き、目覚まし時計が揺れて鳴り、壁の時計が光る。9.6〜9.95秒：燃料計が満タンへ戻り、集中線ときらり。暗さが消えて朝になる。字幕「枠が戻るのを待って」 |
| 11〜13 | 続きから | 11.0秒：コンティが潮を吹いて飛び起きる（集中線とびっくりマーク）。11.45秒：Claude Code の横へ泳いで起こし、Claude Code が驚いて跳ねる。12.05秒：作業台のカットへ戻り、Claude Code が続きを作り、コンティが横でヒレを振る。11.3秒から左上の小窓に、自分の席で寝ている開発者。字幕「勝手に続きから」 |
| 13〜15 | 締め | 「尽きたら寝て待つ」・「continuo」・URL・眠るコンティ |

**区切りの時刻を時計の赤い印で示す。**利用枠が戻る時刻に針が届いた瞬間に満タンへ戻すことで、「時刻が来たから戻った」と字幕なしでも読める。

### 効果音

| 秒 | 音 | 動き |
| --- | --- | --- |
| 2.1・3.3 | typing | 猛烈に作業する |
| 5.25 | wait_quota_empty | 燃料計が空になる |
| 5.55 | splat | 座り込む |
| 7.7〜9.6 | wait_quota_tick | だんだん速くなるチクタク（早回しの手前から） |
| 9.6 | wait_quota_bell・wait_quota_charge | ベルと、燃料計が満タンへ戻る音 |
| 11.0・11.45・12.05・13.0 | spout・pop・sparkle・pop | 飛び起きる・起こす・続きを始める・締めの字 |

`wait_quota_*` は `scripts/sfx_wait_quota.py` で合成した。

## 3. 要る絵の一覧

**言いたいこと。**新しく描いた絵は2枚で、残りは既存の絵と Remotion の部品で作る。

| 絵 | 中身 | 作り方 |
| --- | --- | --- |
| `ep/wait_quota/cc_slump` | 力尽きて床に座り込む Claude Code。半目で頭を傾ける | Codex。参照は `assets/ref/claude_code.png` と `characters/robot/sleep.png` |
| `ep/wait_quota/dev_sleep` | 椅子にもたれて眠る開発者。丸い顔のまま目を閉じる（小窓では裏返して左向き） | Codex。参照は `assets/ref/developer.png` と `characters/developer/sip_coffee.png` |
| `claude_code/work`・`wake` | 作る・驚いて起きる | 既存 |
| `continuo/sleep`・`leap`・`wave` | 眠る・跳ねて潮を吹く・ヒレを振る | 既存 |
| `backgrounds/workshop`・`corner`・`desk`、`props/bench` | 作業台の部屋・部屋の隅・小窓の机 | 既存 |

**新しい絵は緑一色（#00FF00）の背景で描かせ、`scripts/key_green.py` で抜いた。**元の絵は `out/work/wait_quota/raw/` にある。

**Remotion で描くもの。**`src/videos/wait_quota/Gauges.tsx` に、燃料計（`FuelGauge`）・壁の時計（`WallClock`）・目覚まし時計（`AlarmClock`）・眠りの「Z」（`Zzz`）を置いた。針と燃料の量を毎フレーム計算するので、減る・満タンへ戻る・早回しが滑らかに動く。
