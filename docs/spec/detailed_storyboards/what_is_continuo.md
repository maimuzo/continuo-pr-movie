# continuo とはの回　詳しいコンテ

**言いたいこと。**「herdr という端末の上で、continuo と Claude Code が並んで動き、カンバンの Status に合わせて pane が開く・止まる・畳まれる」という仕組みの全体を30秒で見せる回の、作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「continuo とはの回」の表と1節の共通の決まりが正である。この回には絵コンテが無いので、構図はこの文書で決める。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。コンティが continuo、テラコッタ色の丸いロボット2体がどちらも Claude Code を演じ、この回に Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**場面を割らず、1枚の herdr の画面を通しで映す。カードの動きと pane の動きを同じ瞬間に起こし、その対を見せる。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、900フレーム（30秒） | storyboard.md の「この回も尺を30秒にする」。pane が開く・止まる・畳まれる流れを Status ごとに読み取らせる |
| 間 | カードの動きと pane の動きは 0.5〜1秒ずつあけて1つずつ起こし、何も起きない間を2秒より短くする | 30秒に延びた時間を、出来事を重ねずに見せるために使う |
| カット | 割らない。2〜13秒は同じ herdr の画面で、時刻だけが進む | pane が増えて減る流れが、カットを割ると途切れて見えなくなる |
| 主役 | herdr の窓が画面のほぼ全部（16px の余白）。上の帯・タブの帯・pane の区切り線と帯を描く | 人間の指摘「herdr 上で continuo と claude code cli が動いているイメージ」 |
| 看板 | 上の帯の左に「herdr」を 78px の等幅の太字で、光る枠に入れて出す。ロゴは描かない | 字幕（64px）より目立たせる。ロゴを描かないのは1節の決まり |
| カンバン | 右上の小窓（506×200）。列は `Ready`・`In Progress`・`Blocked`・`In Review`・`Done` の5つ。カードは番号（#12・#15）と色の札だけ | 脇役なので、列の見出しとカードが読めれば足りる。`Blocked` を見せるので5列が要る |
| 開発者 | 小窓の左横に小さく（高さ 186px）立ち、最後まで動かない | pane を覗き込まず、カンバンだけを触る（symphony の「仕事を管理する」） |
| 字幕・名前の札・締め | 字幕は表の文言のまま画面の下に1行。1行に入らない長さの字幕は、幅 990px に収まるまで字を小さくする（上限 64px）。Claude Code が pane に出たとき、頭の上にテラコッタの札を1.4秒 | storyboard.md の1節の決まり |
| 対の動き | カードが列に着いた瞬間に、その列の見出しを光らせ、同じフレームで pane が開く・帯の色が変わる・畳まれる | storyboard.md の「カンバンの動きと herdr の pane の動きが対になっていることが、この回の筋」 |

### 画面の割り付け

| 場所 | 座標（左・上・幅・高さ） | 中身 |
| --- | --- | --- |
| 上の帯 | 16・16・1048・120 | 窓の3つの丸、「herdr」の看板 |
| タブの帯 | 16・136・1048・54 | `1 continuo`（選ばれている）・`2 shell` |
| continuo の pane | 16・230・340・下まで | 帯「continuo」、その下に「symphony の仕様で実装」の札、`$ continuo` と数行の字、コンティ |
| 右の場所 | 356・230・708・下まで | Claude Code の pane が開く。1つなら全部、2つなら半分ずつ。#15 の pane が畳まれたあと、#18 の pane が同じ場所に開く |
| 小窓 | 548・22・506・200 | カンバン。開発者はその左（中心 x=494） |

**pane の帯の色。**ふだんは灰青、`Blocked` の間は黄色、`In Review` に着くと薄い青にする。黄色は storyboard.md の指定で、青は小窓の `In Review` の見出しの色に合わせた。

| 秒 | 小窓（カンバン） | herdr の画面 |
| --- | --- | --- |
| 0〜2 | — | pane が2つ開いた画面をぼかして映し、タイトル「continuo とは」を重ねる |
| 2.0〜3.0 | — | 真っ黒な画面に `$ herdr` と打つ（2.25〜2.8）。2.85 で Enter |

## 3. 秒ごとの作り（17〜30秒）と、要る絵と音

**言いたいこと。**#15 が PR を出して `In Review` へ、開発者が結果を見て `Done` へ動かすとその pane が畳まれ、次の #18 でまた pane が開く。締めで「見るのはエージェントでなく、仕事」と言う。

| 秒 | 小窓（カンバン） | herdr の画面 |
| --- | --- | --- |
| 17.6 | — | #15 の Claude Code が「PR ✓」の紙を両手で掲げて跳ね、キラリ |
| 18.4〜18.7 | コンティが #15 を `In Review` へ。18.7 に見出しが光る | 18.7：#15 の pane の帯が薄い青になる |
| 19.9 | — | #15 の pane に `› waiting for review` が出て、紙をもう一度掲げる |
| 21.3〜22.0 | 開発者が小窓を指さして #15 を見る。カードの横に緑の「✓」とキラリ | — |
| 22.2〜22.5 | 開発者が #15 を `Done` へ。22.5 に見出しが光る | 22.5〜22.9：コンティが体を振り、#15 の pane が看板ごと畳まれ、#12 の pane が右の場所を全部使う。左の pane に `› close #15 pane` |
| 23.3 | 視線がまた光る | コンティにびっくりマーク。見張り直す |
| 24.0〜24.5 | 開発者が #18 を `Ready` に置く | — |
| 25.0〜25.3 | コンティが #18 を `In Progress` へ。25.3 に見出しが光る | 25.3：空いた場所に「Claude Code: issue #18」の pane が開き、worktree の看板（札は #18 の紫）と Claude Code。名前の札 |
| 27〜30 | — | 締め。「見るのはエージェントでなく、」（60px）と「仕事」（170px）の2行、下に continuo と URL、コンティ |

**締めを2行に割る。**15文字を1行に入れると、150px の字では画面から大きくはみ出す。文言は変えず「、」の後ろで割り、言いたい「仕事」を大きくした。

**symphony の思想。**切り離された実行は、issue ごとに pane と worktree の看板が1つずつ開くことで見せる。自律した実行は、開発者が触らないのに pane が進み、`Blocked`・`In Review` を自分で知らせることで見せる。仕事を管理することは、開発者が小窓の横から動かないことと締めの字幕で見せる。

### 要る絵

| 絵 | 出どころ |
| --- | --- |
| コンティ | `characters/continuo/sleep`・`leap`・`wave` |
| Claude Code | `characters/claude_code/wake`・`work`、`ep/blocked/cc_confused`、新しく描いた `ep/what_is_continuo/cc_pr`（「PR ✓」の紙を頭の上に掲げる） |
| 開発者 | `ep/direct_chat/dev_drag`（カードを動かす）・`dev_laptop`（コメントを書く）・`dev_point`（裏返して小窓を指さす）、`ep/visible_workshop/dev_watch`（見ている） |
| 端末・小窓・看板 | Remotion で描く。worktree の看板は `src/components/WorktreeSign.tsx` |

### 音

既存の `typing`・`enter`・`whoosh`・`sparkle`・`spout`・`pop`・`splat`・`swish` と `blocked_huh` を、上の表の動きの瞬間に鳴らす。pane が開く・畳まれるときは `whoosh`、帯の色が変わるときは `pop` にそろえる。
