# 置くだけの回　詳しいコンテ

**言いたいこと。**「`Ready` に置くだけで、continuo が拾って Claude Code に着手させる」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「置くだけの回」の表と1節の共通の決まりが正で、場面ごとの構図と演技は絵コンテ `out/storyboards/place_on_ready/{2-5,5-8,8-11,11-13}.png` を見本にする。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。continuo の役はクジラのコンティ、Claude Code の役はテラコッタ色の丸いロボットで、この回に Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**場面ごとにカットを割り、どのカットでもカンバンを画面の中に丸ごと収める。絵柄は設定画と同じ、太い線と影1段の平らな塗りにそろえる。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム、無音 | 制作設計の「書き出しと X の仕様」の節 |
| カット | 机・カンバンの壁・作業台の3つの絵を、場面ごとに切り替える。カメラは動かさない | 横長の部屋を横に振ると、正方形の画面にカンバンが収まらず端で切れる。絵コンテも場面ごとに構図が違う |
| カンバン | 机のカットでは右上に 0.9倍、壁のカットでは 1.1倍で置き、枠まで画面の中に収める | 「`Ready` に置く」「`In Progress` へ移す」が見どころなので、列の見出しが切れると話が伝わらない |
| 絵柄 | 背景もキャラクターも、太い輪郭線・平らな塗り・くっきりした影1段。カンバン・カード・看板も Remotion で同じ線の太さで描き、ぼかした影を付けない | 細かく描き込んだ背景に平らなキャラクターを置くと、絵柄が混ざって見える |
| 開発者の顔 | 丸い輪郭と、眼鏡の奥の大きな瞳。絵を伸び縮みさせる弾みを付けない | characters.md の開発者は可愛い顔で、顔をつぶしたり歪めたりしない |
| 字幕 | 画面の下に1行。白い太字に濃い縁取り。文言は storyboard.md の字幕の列のとおり | 無音で見られるので、何が起きたかを字幕で補う |
| 名前の札 | Claude Code が初めて画面に出たとき、頭の上にテラコッタの札を1.5秒浮かべ、白い字で「Claude Code」と書く | storyboard.md の1節の決まり。形が同じロボットを色だけで見分けさせないため |
| 締め | 13.0秒の1コマ目から「置くだけ」を出し、下に小さく「continuo」と `github.com/maimuzo/continuo`、その下にコンティ | 締めは13〜15秒。字を透明から出すと、13秒の時点で字が無い |

### カットと、その中の配置

| カット | 使う場面 | 配置 |
| --- | --- | --- |
| 机（`backgrounds/desk`） | タイトル・場面2・場面5 | 左に机とノートパソコン。開発者はその右の椅子で左を向く。背中側の壁の右上にカンバン |
| カンバンの壁（`backgrounds/corner`） | 場面3 | 上にカンバンを大きく。左下の隅のクッションでコンティが眠る |
| 作業台（`backgrounds/workshop` と `props/bench`） | 場面4 | 手前に作業台（別の絵で重ねる）。その奥に Claude Code、左にコンティ。看板は作業台の前の板に掛ける |

**作業台を別の絵にする。**Claude Code を作業台の奥に立たせ、下半身を台で隠すためである。背景に台まで描くと、ロボットが台の手前に浮いて見える。

## 2. 場面ごとの作り（前半：0〜8秒）

**言いたいこと。**6つの場面に分け、本編の4場面（2〜13秒）を storyboard.md の4行と1対1に対応させる。前半は、カードが `Ready` に貼り付き、コンティが `In Progress` へ移すまでである。秒は動画の頭からの秒である。

### 場面1　タイトル（0〜2秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 机のカットを、キャラクター無しでぼかして映す。手前に大きくタイトル「置くだけで、始まる」 |
| 動き | 1.7〜2.0秒でタイトルが縮んで消える |

### 場面2　開発者が issue を書いて、放る（2〜5秒）

| 項目 | 中身 |
| --- | --- |
| 開発者 | 2.0〜3.25秒：ノートパソコンを打つ。3.25〜3.9秒：紙を丸める。3.9秒〜：振り向かずに、肩越しに手を後ろへ振り上げる（片手にマグカップ） |
| カード | 2.15〜3.2秒：ノートパソコンの上に大きなカードが浮かび、行が左から伸びて書き上がる。3.2〜3.45秒：開発者の手もとへ縮みながら寄る。4.0〜4.6秒：紙の玉が点線の軌跡を残して、大きな弧で `Ready` 列へ飛ぶ。4.6秒：平らなカードになり、横に潰れてから戻って貼り付き、押しピンが付く |
| カンバン | 4.6秒：`Ready` の見出しが一瞬光る |
| 効果 | 打つ手にスピード線。丸めるときと貼り付くときに「くしゃ」の線。貼り付いた瞬間に、カードのまわりへ放射状の線 |
| 字幕 | 「issue を書いて、Ready へ」 |

**書く・丸める・飛ぶ・貼り付くを、重ねずに順に見せる。**どれかが重なると、何が起きたか読み取れない。カードを大きく出すのも、軌跡を残すのも、同じ理由である。

### 場面3　コンティが跳ね起きて、カードを移す（5〜8秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | カンバンの壁のカット。`Ready` に、場面2で貼り付いたカードがある |
| コンティ | 5.0〜5.8秒：クッションの上で泡を出して眠る。5.3秒：カードのあたりに「ぺた」の線（音の代わり）。5.8〜6.5秒：目を開け、潮を吹いて跳ね上がる。6.5〜6.95秒：右向きに浮かんでカードの左下へ泳ぐ。6.95〜7.5秒：前ヒレの先でカードを押して `In Progress` へ移す |
| カンバン | 7.5秒：`In Progress` の見出しが一瞬光る。カードを動かしているあいだは押しピンを外す |
| 効果 | 目を開けた瞬間に集中線とびっくりマーク。泳ぐときと押すときにスピード線 |
| 字幕 | 「continuo が拾って」 |

## 3. 場面ごとの作り（後半：8〜15秒）

**言いたいこと。**後半は、Claude Code が受け取って作り始め、開発者はコーヒーを飲み、締めに「置くだけ」を出すまでである。

### 場面4　看板を掛け、Claude Code に渡す（8〜11秒）

| 項目 | 中身 |
| --- | --- |
| コンティ | 8.0〜8.4秒：カードを持って左から浮かんで来て、作業台の左上で止まる |
| 看板 | 8.35〜8.55秒：「worktree」の看板が上から落ちて、作業台の前の板に掛かる |
| Claude Code | 8.6秒：作業台の奥から跳ねて出る。8.7〜10.2秒：頭の上に名前の札。8.6〜9.85秒：両手を差し出す。9.15〜9.55秒：コンティからカードを受け取る。9.85秒：両手の拳を握って跳ね、気合を入れる（ピースではない）。10.45秒〜：作業台の前で小刻みに揺れて作る |
| カード | 9.7〜10.0秒：上へ弧を描いて看板の札へ飛び、吸い込まれる。どの issue の作業台かを示すため |
| 効果 | 看板にきらり。気合の瞬間にきらりとびっくりマーク。作るときに汗とスピード線 |
| 字幕 | 「Claude Code が作業開始」 |

**カンバンのカードは `In Progress` に残す。**コンティが Claude Code に手渡すのは、同じ見た目のカードである。カンバンのカードまで持っていくと、`In Progress` の列が空になり、場面3で移した意味が消えるためである。

### 場面5　開発者はもうコーヒー（11〜13秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 机のカットに戻る。カンバンの `In Progress` にカードが1枚。左上に小窓（11.15〜13.0秒） |
| 開発者 | 椅子にもたれて脚を組み、大きな目のまま満足げにマグカップをすする。湯気が立つ |
| 小窓 | 作業台の奥で揺れながら働く Claude Code と、その横でヒレを振るコンティ |
| 字幕 | 「あなたは、コーヒーでも」 |

### 場面6　締め（13〜15秒）

| 項目 | 中身 |
| --- | --- |
| 構図 | 無地の背景。中央に「置くだけ」、その下に小さく「continuo」と `github.com/maimuzo/continuo`、下にコンティ |
| 動き | 「置くだけ」は13.0秒の1コマ目から見えていて、大きい字から縮んでドンと収まる。コンティがぴょんと跳ねる |

## 4. 要る絵の一覧

**言いたいこと。**この回で使う絵は、キャラクター10枚（コンティ3・Claude Code 3・開発者4）、背景3枚、小道具1枚である。コンティの3枚は設定画から切り分け、残りは Codex に描かせた。

| 絵 | 中身 | 使う場面 | 作り方 |
| --- | --- | --- | --- |
| `continuo/sleep`・`leap`・`wave` | 眠る・跳ねて潮を吹く・浮かんでヒレを振る（左向き。右へ向かうときは裏返す） | 場面3・4・5・6 | `assets/raw/continuo/sheet.jpeg` から `scripts/cut_continuo.py` で切り分け |
| `claude_code/receive` | 両手を差し出して受け取る | 場面4 | Codex。参照は `assets/ref/claude_code.png` |
| `claude_code/fist` | 両手の拳を胸の前で握って気合 | 場面4 | 同上 |
| `claude_code/work` | 前かがみで手を動かして作る | 場面4・5の小窓 | 同上 |
| `developer/typing`・`crumple`・`throw`・`sip_coffee` | 打つ・丸める・肩越しに放る・もたれてすする。どれも椅子ごと、左向き | 場面2・5 | Codex。参照は `assets/ref/developer.png`。顔は丸い輪郭と大きな瞳と指定した |
| `backgrounds/desk`・`corner`・`workshop` | 机・カンバンの壁・作業台の部屋。キャラクターとカンバンは描かない | 全場面 | Codex。参照は同じ場面の絵コンテ |
| `props/bench` | 正面から見た作業台。ノートパソコンの背と、工具とメモ | 場面4・5の小窓 | Codex |

**キャラクターと小道具は、緑一色（#00FF00）の背景で描かせて `scripts/key_green.py` で抜く。**描かせた元の絵と抜いた絵は `out/work/place_on_ready/` に置き、使う絵を `public/` へ写す。
**拳を握る絵を新しく描いた。**レンチを構える絵で気合を表すと、storyboard.md の「拳を握って気合を入れる」にならないためである。

### Remotion の部品で描くもの

| 部品 | 中身 |
| --- | --- |
| `Kanban` | 壁のカンバン。木の枠、列は `Ready`（緑）/ `In Progress`（黄）/ `In Review`（青）/ `Done`（赤）の見出し。`scale` で大きさを変える |
| `IssueCard` | 紙のカード。丸めた形・書きかけ（`written`）・貼り付いた瞬間の潰れ（`squash`）・押しピン（`pin`） |
| `WorktreeSign` | 作業台の看板と、カードと同じ色の札 |
| `NameTag` | 頭の上の名前の札（丸い札・白い字・下に三角） |
| `TitleCard` / `Caption` / `EndCard` | タイトル・場面ごとの字幕・締め |
| `Effects` | 集中線・びっくりマーク・汗・湯気・スピード線・きらり・「くしゃ」の線 |
| `Inset` | 左上の小窓 |
