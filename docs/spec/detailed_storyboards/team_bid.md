# チームで入札の回　詳しいコンテ

**言いたいこと。**「チームで1枚のカンバンを共有すると、残りの利用枠がいちばん多い Claude Code の机へカードが渡る」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「チームで入札の回」の表と1節の共通の決まりが正で、構図と演技は絵コンテ `out/storyboards/team_bid/{2-6,6-10,10-13}.png` を見本にする。絵コンテと食い違うところは、この文書とコンテを正とする。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。この回に Codex と開発者は出ない。

## 1. 共通の決まり

**言いたいこと。**1つの部屋のカットだけで通し、残りの枠は Claude Code の頭の上の燃料計に出す。コンティは1頭にする。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の「書き出しと X の仕様」の節 |
| カット | チームの部屋（`ep/team_bid/room`）を1枚、カメラを動かさない | 3つの机とカンバンを同時に見せないと、どの机へ渡ったかが読めない |
| 配置 | 上に共有のカンバン（等倍、枠まで画面の中）。下に机3つ（左右 20〜1060px）、各机の奥に Claude Code が1体座る | 正方形の画面に、カンバンと3つの机を切らずに収めるため |
| 役 | Claude Code 3体（メンバーの机3つ）とコンティ1頭 | 残りの枠を持つのは Claude Code。コンティを3頭にすると、コンティが枠を持っているように見える（人間が決めた） |
| 燃料計 | 各 Claude Code の頭の上に、電池の形の燃料計と％の数字。中身は黄色（#F2C14E）で、緑にしない。Remotion で描き、減る動きを付ける | 1節の「計器の形」。黄色は人間の指示 |
| 入札 | 新しいカードが出るたびに、3つの数字が弾む。いちばん大きい机の数字と燃料計が黄色く光り、星が出る | 「数字を出す＝入札」「光る＝取った」を無音でも読めるようにする |
| 名前の札 | 2.05〜3.35秒、3体それぞれの**頭の上**にテラコッタの札「Claude Code」。札が消えてから燃料計が出る | 1節の決まり。絵コンテでは札がカンバンの上にずれていたので直した |
| 字幕・締め | 字幕は表のとおり。締めは「空いてる人へ、/どんどん」の2行 | 11字を1行にすると、共通の締めの字の大きさでは画面に収まらない |
| タイトル | 「チームで、入札」 | コンテの表にタイトルの文言が無いので、回の呼び名から取った |

## 2. 場面ごとの作り

**言いたいこと。**本編の3場面を storyboard.md の3行と1対1に対応させる。秒は動画の頭からの秒である。燃料の動きは 72/35/10 → 机A、30/35/10 → 机B、30/12/10 → 机A、8/12/10 → 机B、8/4/10 → 机C で、どの回もいちばん大きい数字の机が取る。

| 秒 | 何が起きるか |
| --- | --- |
| 0〜2 | タイトル。0.35・0.85・1.35秒に、カードが上から `Ready` へ落ちて積まれる。机はまだ空 |
| 2.0〜2.3 | Claude Code 3体が机の奥から跳ねて出る。2.05〜3.35秒、頭の上に名前の札 |
| 3.3〜3.5 | 3体の頭の上に燃料計が出る |
| 3.5 | 新しいカードが `Ready` に落ちる |
| 3.75〜4.0 | 72%・35%・10% が順に弾んで浮かぶ（入札） |
| 4.25 | 72% の机Aが黄色く光り、星が出る |
| 4.25〜5.3 | コンティがカードを取り、弧を描いて机Aへ運ぶ。机Aは受け取って作り始める。5.3〜5.9秒に燃料が 72% → 30% へ減る |
| 6〜10 | 右上に「早回し」の印。6.1・7.05・8.0・8.95秒に新しいカードが出て、同じ入札を早回しで4回。カードは机B → 机A → 机B → 机C と、そのときいちばん数字の大きい机へ流れる。数字が 20% を切った机の Claude Code は頬杖で座ったまま待ち、汗をかく |
| 10.15〜11.65 | 机に積んだ5枚のカードが、0.25秒おきに `In Review` へ飛び、重なって列が埋まる。3体はピースで跳ね、コンティは真ん中で喜ぶ |
| 13〜15 | 締め「空いてる人へ、どんどん」。下に `continuo` と `github.com/maimuzo/continuo`、その下にコンティ |

**早回しでも、入札 → 光る → 運ぶ → 減る の順は崩さない。**順が崩れると、「数字が大きいから選ばれた」ことが読めなくなる。

### 効果音

| 秒 | 音 |
| --- | --- |
| 0.53・1.03・1.53 | カードが積まれる（splat、小さめ） |
| 2.0 | 3体が出る（pop） |
| 各回の新しいカード | splat |
| 入札 | `team_bid_bid`（ピッ）。最初の回は3体ぶん鳴らす |
| 選ばれた瞬間 | `team_bid_win`（ピロン） |
| 運ぶ | 最初の回は whoosh、早回しは swish |
| `In Review` に届く | pop |
| 10.25・11.5 | spout・sparkle |
| 13.0 | 締めの字（pop） |
