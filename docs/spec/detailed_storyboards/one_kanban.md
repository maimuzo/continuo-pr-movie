# カンバン1枚の回　詳しいコンテ

**言いたいこと。**「1枚のカンバンで、複数の GitHub リポジトリの issue を同時に進められる」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「カンバン1枚の回」の表と1節の共通の決まりが正で、構図は絵コンテ `out/storyboards/one_kanban/{2-5,5-10,10-13}.png` を見本にする。
キャラクターの見た目は [docs/spec/characters.md](../characters.md) にある。この回に Codex は出ない。

---

## 1. 共通の決まり

**言いたいこと。**「別々のリポジトリ」を、色と名前の両方で結んで見せる。カードの帯・工房の屋根・作業台の札・進み具合の棒を、リポジトリごとに同じ色にそろえる。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| 画面 | 1080×1080、30fps、450フレーム | 制作設計の書き出しの決まり |
| リポジトリ | `acme/shop-app`（赤 #E05B45）・`acme/api`（黄 #F1AF3C）・`acme/docs`（紫 #9E68D0）の3つ。色は背景の絵の屋根を測った値 | 色だけでは「リポジトリ」だと分からないので、看板に名前を書き、カードの帯にも短い名前を書く |
| 看板の字 | 絵には字を描かせず、Remotion で看板の板の上に書く | 描かせた字は崩れることがあり、架空の名前を正確に出せない |
| カット | カンバンの壁（`backgrounds/corner`）と、3軒の工房（`ep/one_kanban/workshops`）の2つ。カメラは動かさない | 工房のカットの上の壁にカンバンを掛け、カンバンと3軒を同じ画面に収める |
| 3体の Claude Code | 3軒それぞれに1体。初めて出たとき、3体とも頭の上にテラコッタの名前の札を1.5秒 | 「3体が同時に」を数で見せる。名前の札は1節の共通の決まり |
| 開発者の顔 | 伸び縮みの弾みを付けない。貼るたびに少し背伸びするだけ | characters.md の、顔をつぶさない決まり |
| 締め | 13.0秒から「1枚で全部回す」。7字あるので、共通の締めを `src/videos/one_kanban/EndCard.tsx` に写し、字を124pxにした | 150px のままだと、大きい字から縮める頭のコマで左右が切れる |

## 2. 場面ごとの作り

**言いたいこと。**本編の3場面を storyboard.md の3行と1対1に対応させる。秒は動画の頭からの秒である。

| 場面 | 秒 | 中身 | 字幕 |
| --- | --- | --- | --- |
| 1 タイトル | 0〜2 | 工房のカットをぼかして映し、手前に「カンバンは1枚でいい」。1.7秒から縮んで消える | — |
| 2 並べる | 2〜5 | 左に立つ開発者（片手にマグ）が、上げた右手から `Ready` 列へカードを1枚ずつ貼る。2.62秒 shop-app（赤）、3.32秒 api（黄）、4.02秒 docs（紫）。貼り付く瞬間に横に潰れて戻り、押しピンが付く。3枚目のあと `Ready` の見出しが光る | リポジトリが違っても |
| 3 飛ばす | 5〜10 | 上の壁にカンバン、右にコンティ、下に3軒の工房。カードがカンバンから跳んでコンティの頭の上へ、コンティが潮を吹いて跳ね、カードが潮の弧に乗って同じ色の工房の作業台の看板の札へ吸い込まれる（届くのは 6.2・7.55・8.9秒）。届く直前に worktree の看板が落ちて掛かり、届いた瞬間にしぶき・きらり、作業台の奥から Claude Code が跳ねて出て、0.7秒後に作り始める | issue ごとに、そのリポジトリで |
| 4 同時に進む | 10〜13 | 3体が揺れの拍をずらして同時に作る（汗・スピード線）。看板の下の進み具合の棒が3本そろって伸びる。10.2〜10.7秒でカンバンの3枚がそろって `In Progress` へ滑り、見出しが光る。コンティが3軒の屋根の上を左から右へゆっくり泳ぐ | 同時に進む |
| 5 締め | 13〜15 | 「1枚で全部回す」、下に「continuo」と `github.com/maimuzo/continuo`、コンティが跳ねる | — |

**カンバンのカードは、場面3では `Ready` に残す。**手渡すのは同じ見た目のカードで、場面4でカンバンの3枚がそろって `In Progress` へ移る。storyboard.md の「そろって `In Progress` 列に並ぶ」を1回の動きで見せるためである。

## 3. 要る絵と部品

**言いたいこと。**新しく描いた絵は2枚（工房の背景・立って貼る開発者）で、残りは既存の絵と Remotion の部品で作る。

| 絵・部品 | 中身 | 作り方 |
| --- | --- | --- |
| `public/ep/one_kanban/workshops.png` | 上3割が無地の壁、その下に赤・黄・紫の屋根の工房3軒（字の無い看板、屋根と同じ色の箱）、下に床 | Codex。参照は絵コンテ 10-13 と `backgrounds/workshop`。1254px を 1080px に縮めた |
| `public/ep/one_kanban/dev_pin.png` | 立って右を向き、右手を上げて貼る開発者。左手にマグ | Codex。参照は `assets/ref/developer.png`。緑を `scripts/key_green.py` で抜いた |
| 既存の絵 | `claude_code/receive`・`work`、`continuo/wave`・`leap`、`props/bench`、`backgrounds/corner` | そのまま使う |
| `src/videos/one_kanban/Board.tsx` | 共通の Kanban を写し、列を広く高くしたカンバンと、色の帯に名前を書くカード | 1列に3枚を縦に並べ、帯の字を読ませるため |
| `src/videos/one_kanban/repos.ts` | 3つのリポジトリの名前と色、工房の位置 | 色と位置を1か所で決める |

描かせた元の絵と抜いた絵は `out/work/one_kanban/` に置く。効果音は既存の `public/sfx/` の音だけを使う。
