# 止めても続きからの回　詳しいコンテ

**言いたいこと。**「continuo を `Ctrl+C` で止めても pane は閉じず、次に起動すれば続きから」を15秒で見せる回の、場面ごとの作りを決める文書である。
何が起きるかは [docs/spec/storyboard.md](../storyboard.md) の「止めても続きからの回」の表と注記、1節の共通の決まりが正で、構図は絵コンテ `out/storyboards/resume/{2-6,6-10,10-13}.png` を見本にする。
絵柄・字幕・締め・名前の札・効果音の付け方は、お手本の [置くだけの回](place_on_ready.md) にそろえる。

---

## 1. 共通の決まり

**言いたいこと。**全場面を「開発者の PC の画面に窓が2つ並ぶ」1つのカットで見せ、ロボットとクジラを PC の中で動かす。止まるのは左の窓だけで、PC の電源は最後まで点いたままにする。

| 項目 | 決まり | なぜ |
| --- | --- | --- |
| カット | 部屋の壁（`backgrounds/corner`）の前に、Remotion で描いた大きなモニターと机。左下に開発者、机の上に大きな `Ctrl+C` のキー。カメラは動かさない | 人間の指摘で、PC の電源と作業台の関係が分からなかった。同じ画面を最後まで映せば、PC の中の窓の明暗だけが変わったと分かる |
| 窓 | モニターの中に窓を2つ並べる。左は「continuo」の窓でコンティがいる。右は「pane: Claude Code」の窓で、作業台で作業する Claude Code がいる | storyboard.md の行のとおり。窓の題名で、どちらが continuo でどちらが pane かを字で補う |
| 窓の外に出さない | コンティも Claude Code も、自分の窓の中だけで動く（窓の外は切り取る）。渡す紙だけが窓の境目を越える | 絵コンテでは Claude Code が机の上に出てきて、PC の中で動いている絵にならなかった |
| 止まった印 | 左の窓に暗い幕をかけ、題名の帯を灰色にし、「休業」の札を下げる。コンティは目を開けたまま動きを止める。眠る絵は使わない | 眠る絵は、ほかの回で「continuo が動いたまま待っている」の意味に使っている |
| 電源 | モニターの右下の電源の灯りは、全場面で緑に点いたまま。右の窓は一度も暗くしない | PC の電源は切らない。止めるのは continuo だけで、pane は閉じない |
| 夜と朝 | 5秒から部屋（モニターの外）を青く暗くし、6秒で明るい朝に戻して「翌朝」の札と太陽を出す | 「翌朝」を字で言わずに、時間が経ったことを見せる |
| 開発者 | 既存の左向きの絵を裏返して右（モニター）を向かせる。顔に弾みを付けない | characters.md の開発者は可愛い顔で、顔をつぶしたり歪めたりしない |
| 名前の札 | Claude Code が初めて出た2.1秒から1.5秒、右の窓の中の Claude Code の頭の上に浮かべる | 1節の決まり |
| 字幕 | 場面ごとに1行。「continuo を止めても」「作業台は、そのまま」「次に起動すれば、続きから」 | storyboard.md の字幕の列のとおり |
| 締め | 13.0秒から「止めても、消えない」と、continuo の名前と URL とコンティ | お手本と同じ |

## 2. 場面ごとの作り

**言いたいこと。**本編の3場面を storyboard.md の3行と1対1に対応させる。秒は動画の頭からの秒である。

| 場面 | 秒 | 中身 |
| --- | --- | --- |
| タイトル | 0〜2 | 止める前の画面をぼかして映し、「止めても、消えない」。1.7秒から縮んで消える |
| 止める | 2〜6 | 2.0秒：両方の窓が明るい。左でコンティが浮かび、右で Claude Code が作業台の奥で揺れて作る。3.0秒：開発者の手もとに大きな `Ctrl+C` のキーが出る。3.2秒：押す。左の窓だけが0.4秒で暗くなり、3.5秒に「休業」の札が落ちてくる。コンティは止まる。3.7秒〜：開発者はコーヒー。4.6秒：Claude Code が手元の作業を仕上げて拳を握る（きらり）。5.0秒〜：作業台の前に座って待つ |
| 翌朝 | 6〜10 | 6.0秒：部屋が朝になり「翌朝」の札。右の窓では Claude Code が座ったまま待っている。6.4〜7.2秒：開発者が打つと、暗い左の窓に `$ continuo` の字が出る。7.2秒：Enter。7.3秒：左の窓が明るくなり、札が外れる。7.5秒：コンティが潮を吹いて跳ねる。8.1秒：コンティが窓の右の端へ寄る。8.4秒：Claude Code が立って両手を出す。8.5〜9.2秒：紙が窓の境目を越えて Claude Code の手へ渡る |
| 続きから | 10〜13 | 10.0秒：Claude Code が拳を握り、10.4秒から作業台の奥で作る（汗とスピード線）。コンティは左の窓でヒレを振る。10.3秒：開発者が頬杖をついて拍子抜けし、汗のしずく |
| 締め | 13〜15 | 「止めても、消えない」、下に continuo と URL とコンティ |

**紙は窓の境目の上を飛ばす。**コンティが窓から出ずに渡せるうえ、「continuo が pane の Claude Code に次の指示を送る」ことを1枚の紙で見せられるためである。

## 3. 要る絵の一覧

**言いたいこと。**新しく描いたのは2枚（座って待つ Claude Code、拍子抜けする開発者）で、残りは既存の絵と Remotion の部品である。

| 絵 | 中身 | 作り方 |
| --- | --- | --- |
| `ep/resume/cc_sit_wait` | 床に座り、両手をひざに置いて目を開けたまま待つ Claude Code | Codex。参照は `assets/ref/claude_code.png` と `claude_code/wake` |
| `ep/resume/dev_anticlimax` | 椅子で頬杖をつき、半目で拍子抜けする開発者（左向き） | Codex。参照は `assets/ref/developer.png` と `developer/sip_coffee` |
| 既存 | `continuo/wave`・`leap`、`claude_code/work`・`fist`・`receive`、`developer/typing`・`sip_coffee`、`backgrounds/corner`・`workshop`、`props/bench` | そのまま |

**Remotion で描くもの。**モニター・窓の枠と題名の帯・暗くなる幕・「休業」の札・`Ctrl+C` のキー・`$ continuo` の字・机・「翌朝」の札と太陽・夜の色。
**効果音。**既存の音に加え、`scripts/sfx_resume.py` で「止まる音」（下がる音）と「点く音」（上がる音）を作り、`public/sfx/resume_{off,on}.wav` に置く。
